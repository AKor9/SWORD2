# Пекарня (`Sword.Bake`, exe `sword-bake`) — правила

Сырой файл → конвертер по виду файла → `Content/<тема>/…`. Устройство — README.md.

- Без плагинов и актуальности: новый вид файла — класс в `Converters/` и строка в `Baker.Converters`; кэшей, отпечатков
  кода и «устарело» не заводить. Пак не собирает — это `Sword.Assets`.
- Конвертер читает только через `BakeJob` (`Input`, `InputDir`, `Baker.Rig`) и пишет только `job.Output(путь в Content/)`:
  так лог и окно знают записанное. Запись файла формата — `ContentFiles.Write` (через `*.tmp`).
- Выход детерминирован: те же исходники и рецепт — те же байты (тесты повторной выпечки). Без времени, путей машины и
  сборок в выходе.
- Рецепты и `pak.json` пишет `TextFiles` (CRLF у новых). Пути в параметрах — через корни `${src}/…`.
- Тесты пекарни — только во временном каталоге (`--bake`, `--content`): не трогать `Bake/recipes` и `Content/` репозитория.
- Сторона `Neutral`; ссылки — Content, Formats, Animation, Game.Data (матрица `ArchitectureRules`).

Проверка: `dotnet test tests/Sword.Bake.Tests` (синтетика; `SourceFact` — оружие на настоящем риге, без исходников —
пропуск); виды — `sword-bake --kinds`; всё — `sword-bake --all` в рабочем дереве (~46 с Debug).

Типичные ошибки:
- код 3 «рецепта нет» — первая выпечка: `--set поле=значение` или `--yes`; «годятся несколько конвертеров» — `--converter`.
- «вне корней сырых исходников» — нет корня в `Bake/bake.user.json` (рабочее дерево: скопировать из основного).
- «rig …: нет рецепта» — сначала испечь `skeleton.json` (рецепт скелета).
- «Access to the path is denied» при выпечке — файл `Content/` открыт другим процессом (тест не закрыл поток).
