# Пекарня `sword-bake`

Перегоняет сырые исходники (выгрузки Unreal, glTF, PNG, TTF, JSON) в игровые ресурсы: выбрал сырой файл → конвертер
по виду файла (или сообщение «конвертера нет») → файлы игровых форматов в `Content/<тема>/…`. Что из `Content/`
идёт в пак и сама сборка пака — менеджер ресурсов [Sword.Assets](../Sword.Assets/README.md); окно пекарни — его вкладка
«Пекарня». Рецепты, корни и происхождение — [Bake/](../../Bake/README.md).

## Виды файлов

| конвертер | сырой файл | выход в `Content/` |
|---|---|---|
| `anim` | `manifest.json` выгрузки (рядом `clips/`) | `animations/<набор>/*.swclip` — все клипы выгрузки по наборам `sets` |
| `skeleton` | `skeleton.json` (поза покоя) | `skeletons/<id>.swskeleton`; рецепт — риг для остальных |
| `weapon` | `*.glb`, `*.gltf` | `meshes/weapons/<имя>.swmesh`, `data/weapons/<имя>.swblood` |
| `character` | `*.glb`, `*.gltf` | `meshes/characters/<имя>.swmesh` |
| `anatomy` | `*.glb`, `*.gltf` | `meshes/characters/anatomy/<имя>.swmesh` |
| `texture` | `*.png` | `textures/<имя>.swtex` (или `out`) — массив слоёв `layers` |
| `font` | `*.ttf` | `fonts/<имя>.swfont` и лицензии `extra` рядом |
| `copy` | `*.json`, `*.txt` (кроме выгрузки и позы покоя) | `data/<имя файла>` (или `out`) |

Порядок таблицы (`Baker.Converters`) — порядок выбора, когда файлу годятся несколько (glTF): первая выпечка требует
выбора (`--converter`), дальше он в рецепте. Путь файла в паке = путь в `Content/`.

## Рецепт

`Bake/recipes/<корень>/<путь сырого файла от корня>.bake.json` — конвертер, `import` (ключ `Bake/imports.json`),
`notes` и `params` (класс параметров конвертера, camelCase). Рецепт лежит не рядом с сырым файлом: исходники вне git,
а параметры (хват, зоны крови, наборы) терять нельзя. Пути в параметрах — через корни машины `${src}/…`, `${assets}/…`
(`Bake/bake.user.json`, переменная `BAKE_ROOT_ИМЯ`). Файл вне корней не печётся.

Первая выпечка спрашивает параметры: в окне — форма, в CLI — код 3 с параметрами по умолчанию, ответ ключами
`--set поле=значение` (JSON или строка; вложенное — `blood.handleEnd=25`) или `--yes`. Рецепт пишется после удачной
выпечки; дальше выпечка идёт по нему без вопросов.

Риг: рецепт скелета (сырой файл — `skeleton.json`) хранит ID скелета, эталонный экспорт `clips` и `fingerSrc`;
анимация, меш персонажа, оружие и анатомия ссылаются на него полем `rig` (путь его `skeleton.json`). Без рецепта
скелета они не пекутся; единственный рецепт скелета подставляется в `rig` по умолчанию.

## CLI

```
sword-bake ФАЙЛ [--converter ID] [--set поле=значение]… [--yes]   испечь по рецепту; нет рецепта — спросить
sword-bake --all                                                   испечь все рецепты (параллельно)
sword-bake --kinds                                                 таблица видов файлов
[--bake КАТАЛОГ --content КАТАЛОГ]                                 по умолчанию Bake/ и Content/ репозитория
```

Коды: 0 — испечено, 1 — ошибка, 2 — конвертера нет, 3 — нужны параметры. `--all` на 34 рецептах `Bake/` — 1088 файлов,
~46 с (Debug).

## Устройство

- `Baker` — таблица видов, пути рецептов, выпечка; `Recipe` — файл рецепта; `SourceRoots` — корни машины.
- `Converters/` — по классу на вид: параметры и `Bake(job, params)`; `BakeJob` — входы через корни и выходы в `Content/`.
- `Anim/` — raw-экспорт, glTF, скиннинг, хват оружия, зоны крови, анатомия; `Texture/` — PNG и BC-сжатие; `Font/` —
  контуры TrueType. NuGet — только StbTrueTypeSharp.

## Ограничения

- Ничего не отслеживает: нет кэша, отпечатков кода и актуальности. Перепечь — запустить ещё раз.
- Клип, пропавший из выгрузки, остаётся в `Content/`: удалить файл или выключить в менеджере.
- Один рецепт на сырой файл: две текстуры из одной картинки — рецепты у разных файлов слоёв (`light_noise` у
  `T_Noise3.png`, `sim_noise` у `T_NoiseTemplate1.png`).
- `SourceHash` клипа — хеш исходника без сборок пекарни (сведения о происхождении): те же исходники — те же байты.
- Пути тем — константы игры и движка: `ClipLibrary.AnimDir`, `UiVectorFontFormat.Dir`, `WeaponMesh.Dir`; остальное —
  `out` рецепта (меш персонажа `CharacterAssets.MeshFile`, действия `ActionTable.ActionsFile`, текстуры огня `FireModule`).
