# Bake Studio (`Sword.Bake.Studio`)

Окно пекарни на движке SWORD2 (сторона `Client`): `Win32Window`, рендер-граф (очистка + UI-проход `Renderer.Ui`), виджеты
`Sword.Engine.Ui`. Выпечку делает ядро (`tools/Sword.Bake`) и обработчики из плагинов проекта — Studio их показывает,
правит манифесты и запускает сборку; всё, что умеет Studio, умеет и CLI `sword-bake`, кроме правки мышью и предпросмотра.
Перенос Studio SWORD 2eab13b на новый движок; правила — AGENTS.md.

## Что умеет

- **Проект**: открыть каталог с `bake.project.json` (или создать проект в пустом каталоге), корни, плагины, актуальность
  ассетов и причины, целостность пака, содержимое пака по файлам, ассетам и импортам.
- **Виды слева**: Контент (ассеты пака по игровому смыслу), Сборка (единицы — манифесты), Импорты, Обработчики.
- **Единица сборки** — вкладки: Свойства (форма из `ParamsType` обработчика: описания, исходники с выбором файла, ссылки на
  другие единицы; Ctrl+S пишет манифест `ManifestWriter`, переводы строк сохраняются), Исходники и выходы, Зависимости,
  Просмотр.
- **Добавить и удалить** ассет, **собрать** пак в фоне (F7; двойной щелчок по ассету — собрать с ним), лог сборки,
  **слежение** за исходниками и манифестами (изменение → проверка статусов → сборка устаревшего; флажок «Следить»).
- **Просмотр** — сцена, которую строит обработчик ассета (`IAssetPreview`) из его выходов в паке; переключатель вариантов
  показа над сценой:

| обработчик | что видно | варианты |
|---|---|---|
| `anim.pack` | клипы набора на меше персонажа из пака (скиннинг на CPU), оружие источника в правой кисти, след root motion; список клипов с фильтром, проигрыватель (пуск/пауза, шкала, скорость; ↑↓ — клип, пробел, ←→ — кадр) | меш, меш и кости, кости |
| `anim.skeleton` | меш персонажа на этом скелете в позе покоя и кости по его bind-матрицам | те же |
| `skin.mesh` | меш в позе покоя, секции цветами с легендой, габариты | секции, сплошной |
| `anatomy.mesh` | то же для анатомии | секции, сплошной, под кожей (полупрозрачный персонаж) |
| `weapon.static` | меш по зонам крови (`.swblood`), контуры зон, главная ось | зоны, зоны и клетки, меш |
| `texture.array` | слои массива с миниатюрами, мипы из файла (BC1/BC4/BC5 распакованы на CPU; BC7 — нет), тексель под курсором | цвет/альфа, значение/маска, нормаль/X/Y |
| `font.vector` | образец текста кеглями 12–64 и таблица 180 знаков интерфейса (нет знака — красная клетка); растр без шейпинга | образец, набор знаков |

  3D-сцена рисуется треугольниками `UiDrawList` (плоский свет, сортировка художника); ЛКМ — вращать, колесо — приблизить,
  двойной щелчок — сброс. Картинки — `Renderer.CreateImage` со своими мипами; колесо — к курсору, ЛКМ — сдвиг, «1:1», мип.

## Запуск

```
tools/Sword.Bake.Studio/bin/Debug/<TFM>/Sword.Bake.Studio.exe [ключи]
```

| ключ | что |
|---|---|
| `--project ПУТЬ` | проект (каталог с `bake.project.json` или внутри него); без ключа — от текущего каталога вверх, не нашёлся — окно выбора |
| `--windowed WxH` | клиентская часть окна, физические пиксели (по умолчанию 1600x900) |
| `--scale K` | множитель масштаба интерфейса поверх масштаба монитора |
| `--select ID` | выбрать единицу; `content:ID`, `import:ID`, `processor:ID` — ассет контента, импорт, обработчик |
| `--tab N` | вкладка: 0 свойства, 1 исходники и выходы, 2 зависимости, 3 просмотр; 4 — проект и пак |
| `--preview-mode N` | вариант показа на вкладке «Просмотр» (0 — первый) |
| `--build-all` | сразу собрать пак |
| `--confirm-delete`, `--add-asset` | открыть вопрос удаления или окно добавления (для снимков; ничего не удаляют сами) |
| `--mouse X,Y` | курсор в точке окна — снимки подсказок и наведения |
| `--shot ФАЙЛ` | снимок (PNG; `.bmp` — BMP), когда статусы проверены и сборка закончена, и выход |
| `--gallery КАТАЛОГ` | снимки всех видов и предпросмотров (`NN-вид.png`), витрина виджетов, лог модели в консоль, выход |
| `--widgets` | витрина виджетов вместо пекарни |
| `--no-activate` / `--activate` | окно без фокуса / с фокусом; `--shot` и `--gallery` — всегда без фокуса; `SWORD_NO_ACTIVATE=1` — умолчание агентов |
| `--debug` | отладочный слой D3D12 с GPU-валидацией |

Открыть проект пекарни репозитория: `Sword.Bake.Studio --project Bake` (плагины — `tools/Sword.Bake.Engine`, `Sword.Bake.Game`
той же конфигурации; пак — пак игры `Content.swpak` в корне, до первой сборки вкладка «Просмотр» просит собрать).

**Шрифты окна** — системные Segoe UI, Segoe UI Semibold, Consolas, запечённые на лету пекарем шрифтов (`UiFontBaker`,
исходник плагина движка, подключён ссылкой); кэш — `%LOCALAPPDATA%\SWORD Bake Studio\fonts` по размеру и времени ttf,
ролям, версии формата и сборке Studio. От проекта и пака не зависят.

## Снимки для агента

- `--shot ФАЙЛ` с `--select`, `--tab`, `--preview-mode` — один вид; `--gallery КАТАЛОГ` — все: проект, ассет контента
  (свойства и просмотр), единица с наибольшим числом параметров на каждой вкладке, **предпросмотр каждого обработчика**
  (`NN-preview-<обработчик>.png` — первая единица, `…-<вариант>.png` — второй вариант у последней: под кожей, набор знаков,
  меш и кости, клетки), импорт, обработчик, окна добавления и удаления, витрина.
- На снимках клип анимации стоит на паузе в начале — снимок не зависит от времени.
- В консоль: строка на снимок (размер, кадр, квадов и вызовов UI-прохода), в конце — лог модели (`[studio] лог …`); снимок по
  таймауту печатает, чем модель занята.
- Снимки на эталонном паке — копия проекта, у которой `pak` указывает на **копию** `Content.reference.swpak`, а не на него:
  со «Следить» изменение исходника или манифеста запускает сборку устаревшего, и она перезаписала бы пак проекта. У `Bake/`
  свой пак (пак игры `Content.swpak`) — его автосборка и должна переписывать (запущенная игра дочитывает прежний); эталону
  обычная работа не грозит.

## Проверка

`dotnet test tests/Sword.Bake.Studio.Tests`: модель без окна на копии `Bake/` (плагины загрузчиком ядра, статусы, форма
параметров туда-обратно на каждом манифесте, запись манифеста, добавление и удаление, сборка против `sword-bake`, шрифты
окна); `PreviewTests` — предпросмотр каждого обработчика кадром интерфейса на эталонном паке (сцена построена, треугольники
нарисованы или картинки ушли в видеопамять и освобождены; манифесты, файлы пака и их хеши после предпросмотров те же);
категория Gpu — `--shot` и `--gallery` на временном проекте: снимки записаны, окно ни разу не было активным.

## Агентские инструменты

Агент видит Studio снимками `--shot`/`--gallery` (без фокуса) и логом модели в консоли; модель, форма и предпросмотры
проверяются без окна (`StudioApp`, `ParamsEditor`, `PreviewPanel` с `UiContext`). Предпросмотр плагина — чистая функция
`IAssetPreview.Preview(пак, пути, вариант)`: её зовёт тест без Studio. MCP-сервера у Studio нет и не нужно: выпечка — CLI
`sword-bake` (`--json`), содержимое пака — `bake diff`/`inspect`.

## Ограничения

- Растр шрифта в предпросмотре — без шейпинга (плагин движка — сторона `Neutral`, HarfBuzz — в `Engine.Ui`).
- BC7 предпросмотр текстур не распаковывает (в паке BC7 нет).
- 3D-сцена — треугольники интерфейса: проекция, сортировка и (у клипа) скиннинг — на CPU каждый кадр проигрывания; меш
  персонажа — 92 тыс. треугольников. Время кадра не замерялось.
