# Менеджер ресурсов (`Sword.Assets`, exe `sword-assets`) — правила

Что из `Content/` идёт в пак, предпросмотр, сборка пака, окно пекарни. Устройство — README.md.

- Выпечку не дублировать: конвертеры, рецепты и корни — только через `Sword.Bake` (`Baker`, `Recipe`).
- Пак собирает только `ContentPack.Pack`: путь в паке = путь в `Content/`, прежний пак цел при ошибке. Исключения —
  только `Bake/pak.json` (по умолчанию в пак идёт всё).
- Предпросмотр читает файлы `Content/` (`DirectorySource`), не пак, и ничего не пишет; вид — по расширению (`Previews`).
- Фоновые потоки только кладут вызовы в очередь и будят окно; состояние меняет `AssetsApp.Pump` на потоке окна.
- Окно агента — без фокуса: `--shot` всегда, иначе `--no-activate` или `SWORD_NO_ACTIVATE=1`.
- Пак рабочего дерева не направлять на `Content.swpak` основного дерева: `pack --out` во временный каталог.

Проверка: `dotnet test tests/Sword.Assets.Tests` (пак и исключения, CLI, модель пекарни; предпросмотр каждого вида на
`Content/` репозитория — без него пропуск; категория Gpu — снимок без фокуса). Глазами:
`sword-assets --no-activate --windowed 1600x900 --select ПУТЬ --shot ФАЙЛ` (`--tab 1 --source ФАЙЛ` — пекарня); лог
модели — в консоль после снимка.
