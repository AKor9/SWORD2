# Менеджер ресурсов `sword-assets`

Готовые игровые ресурсы `Content/` и пак игры: что из `Content/` идёт в пак, предпросмотр ресурса, сборка пака
`Content.swpak`. Вторая вкладка — окно пекарни ([Sword.Bake](../Sword.Bake/README.md)): сырой файл → конвертер →
форма рецепта → «Испечь». Окно — на движке SWORD2 (`Win32Window`, рендер-граф, виджеты `Sword.Engine.Ui`).

## Что в пак

По умолчанию в пак идёт всё из `Content/`. Выключенное — `Bake/pak.json` (в git):

```json
{ "exclude": [ "animations/katana/Anim_DK2_Combo_A1_IP.swclip", "animations/unarmed/" ] }
```

Строка — файл или каталог с «/» в конце. Окно пишет файлы; флажок каталога включает или выключает все его файлы;
включение файла из выключенного каталога раскладывает исключение каталога на файлы. Путь в паке = путь в `Content/`.
Нового файла в `pak.json` нет — он идёт в пак.

## Сборка пака

`ContentPack.Pack` — включённые файлы по возрастанию пути без учёта регистра, без служебных записей. Пак пишется
во временный файл и подменяет прежний целиком: ошибка (нечего класть, сбой чтения) — прежний пак цел. 1088 файлов,
423 МБ — ~1 с.

## Окно

- «Ресурсы»: дерево `Content/` по темам — флажок «в пак», число файлов (выключенных — «N из M»), размер; справа
  предпросмотр выбранного файла или каталога. Строка состояния — сколько файлов и МБ идёт в пак, сколько выключено.
- «Пекарня»: путь сырого файла («Выбрать…» или ввод и «Открыть») → конвертер (выбор, если годятся несколько) → путь
  рецепта (есть или будет записан) → форма параметров → «Испечь» в фоне → список записанного (щелчок — к файлу).
  Нет конвертера — сообщение и таблица видов файлов.
- «Собрать пак» (F7) — в фоне с прогрессом; «Перечитать» (F5) — после выпечки из консоли. Внизу лог.

Предпросмотр (`Preview/`, по расширению — `Previews`): клипы и скелет — на персонаже с проигрывателем; меш персонажа —
по секциям; анатомия — ещё и под кожей; оружие и `.swblood` — по зонам крови; текстура — слои с мипами; шрифт —
образец текста и набор знаков; `.json`/`.txt` — начало текста. Каталог — все файлы вида его первого файла.
Читает файлы `Content/` (`DirectorySource`), не пак.

## Ключи

```
sword-assets pack [--out ФАЙЛ]       собрать пак (по умолчанию Content.swpak в корне) и выйти
sword-assets list [--excluded]       «+ путь размер» / «- путь размер» и выйти
sword-assets check [--out ФАЙЛ]      собран ли пак из текущего Content/ и pak.json (код 2 — нет; шаг content verify.ps1)
[--content КАТАЛОГ --bake КАТАЛОГ]   по умолчанию Content/ и Bake/ репозитория выше текущего каталога
--windowed WxH  --scale K            окно и масштаб интерфейса
--select ПУТЬ  --source ФАЙЛ  --tab N   выбор в Content/, сырой файл пекарни, вкладка (0 ресурсы, 1 пекарня)
--preview-mode N  --shot ФАЙЛ        вариант предпросмотра; снимок, когда окно затихло, и выход
--no-activate | --activate  --debug  фокус (снимок — всегда без), слой отладки D3D12
```

## Устройство

- `ContentPack` — файлы `Content/`, исключения, сборка пака (без окна; его зовут CLI и тесты).
- `AssetsApp` — модель окна: выбор, сырой файл и рецепт пекарни, одна фоновая задача, лог; фоновые потоки кладут
  вызовы в очередь, `Pump` разбирает их на потоке окна.
- `AssetsView` — отрисовка; `RecipeEditor` — форма по классу параметров конвертера (вложенное — JSON строкой);
  `PreviewPanel*` — 3D-сцена, картинки, проигрыватель клипов; `WindowFonts` — системные шрифты окна (кэш
  `%LOCALAPPDATA%\SWORD Assets\fonts`).

## Ограничения

- `Content/` перечитывается по F5 и после выпечки из окна, слежения за файлами нет.
