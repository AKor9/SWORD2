# docs

Документы, которые не принадлежат одному модулю:

- `decisions/` — записи архитектурных решений (ADR), когда решение меняет или уточняет план;
- планы подсистем, когда их устройство не помещается в раздел плана;
- `agent-playbook.md` — рецепты отладки для агентов (с точки 1е плана);
- `history/` — история: журналы точек, решения по ходу, замеры, прежние тексты плана, README и playbook (указатель — `history/README.md`).

Главный документ — [ARCHITECTURE_PLAN.md](../ARCHITECTURE_PLAN.md) в корне репозитория. Документ модуля или фичи
лежит рядом с её кодом.
