Решено на 7г (подробно — история физики, «7г»): `Step(dt)` — поза начала тика → [интеграция → суставы → толчки: начало → земля, стена,
колонны → пары тел на физике (кин ↔ физ — толчок 7д) → толчки: итоги → обновление скоростей → скоростной проход → расслабление суставов]
× подшаги → границы; земля через `IGround` по торцам капсулы (до 6 граней, глубина по текущему положению, старая — по прошлой позе, выход
не быстрее `PopSpeed`). Свои решения против SWORD: бюджет трения покоя общий на тело (μ·Σλn; у SWORD — по касанию, держало до случайной
доли μ), трение скольжения по Кулону в скоростном проходе (без него сорвавшееся тело ползло по склону круче ~1°), стена и колонны держат
всю капсулу (у SWORD — центр тела), в `SegSeg` первым — более короткий отрезок; отсев пар по свежим границам, пары без тела на физике до
`SegSeg` не доходят; 0 Б на 1000 тиков 33 × 14 тел. Риск для 7з (замер проверки): в куче трупов **без суставов** выталкивание с плечом
оставляет вращение, трение скольжения гонит тело обратно в зажим — рост энергии 4…11 Дж за 5…30 с в 4 кучах из 10 (без трения скольжения
≤ 0,3 Дж); направление правки — выталкивать старую глубину без остаточной скорости, ловит `physics.energy`. 53 теста.

Решено на 7д (подробно — история физики, «7д»): толчок живого — кинематическая сторона не двигается, λ ≤ остатка бюджета пары за подшаг
(`PushForce·h²`, один на все контакты пары, первый берёт сколько может), остатка прохода (только клинок) и предела скорости толчка
(толкающая точка ≤ 16 м/с + `PopSpeed`); отдача копится у толкающего, у «за отрубом» нет; удар по части (`ApplyHit`: потолок Δv, списание,
отдача). Свои решения против SWORD: бюджет открытого прохода растёт до наибольшего потенциала (у SWORD задавался при открытии), потенциал
закрытого живёт тик, слот не наследует проходы и отдачу; всё, что влияет на следующий тик, читается через `Pass` и `Reaction`. Трасса физики
— владельцем, выключенная — одна проверка и 0 Б, включённая — 0 Б и симуляцию не меняет (побитово): `Last`/`Window`/`Run`, источники,
скорости и гистограммы, доли бюджетов, выталкивание, Δv, рост энергии за подшаг, контакты последнего подшага, события. Слита поверх 7г
без конфликтов; временный помощник подшага тестов (`KinematicContacts.TestStep.cs`) уходит при сведении физики (7в+7г+7д). 37 тестов.
