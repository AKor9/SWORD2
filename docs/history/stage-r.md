## Р1. HDR и фазы кадра (2026-09-26, L)

- **Сделано.** `FramePhase` (Simulation → Opaque → Composite → Transparent → Post → Ui → Debug): граф устойчиво сортирует проходы по
  фазе (вставками, без выделений), инварианты, барьеры и отчёт — по исполнению; без фазы — Opaque, UI — Ui, отладка — Debug. HDR по

  до Post — исключение графа. Арена включает HDR; шейдеры сцены без `Gamma`; очистка — линейная (`SceneFor` от прежней экранной).
- **Тонмап** (`FilmicTonemap` — CPU-эталон, `common/post.hlsl`) по FSR §3.10а: AP1 (Брэдфорд D65 → D60), ExpandGamut 1, синяя
  коррекция 0.6, glow и red modifier ACES, десатурации 0.96/0.93, S-кривая log10 0.88/0.55/0.26/0/0.04, sRGB. Матрицы — из цветностей;
  числами UE — только таблицы синей коррекции, текст UE не переписан. Числа — в `Contribute`, кривая — корневыми константами (под Р6).
- **Экспозиция 0.99:** бисекция по эталону — 0.18 → pow(0.18, 1/2.2) при 0.99079; при 0.99 байт 117 = прежнему (при 1.0 — 118).
  Белый 1.0 → 0.7232 (байт 221, было 255). A/B одного кадра арены (прежний вывод — из сырого `scene.color`): средний байт яркости
  166.8 → 174.1, R/G/B +4.4/+7.9/+9.6 — чуть светлее и холоднее (десатурации); решать пользователю в игре.
- **Числа.** GPU = эталон ±1/255 на 8 полосах 0…1000; (12, 0.6, 0) → (255, 226, 78), синий > 0. Кадр арены: яркость входа тонмапа —
  максимум 1.18, среднее 0.39, ярче 1 — 0.006 %, NaN нет.
- **Агентские инструменты:** `CaptureResult.Hdr` (экспозиция, максимум, среднее, доля > 1, NaN); `FrameCapture.HdrPath` — карта

  `render.graph` и отчёты проходов — фаза.
- **Отклонения.** HDR — свойство рендера, а не `RendererOptions` (игра получает рендер в `Initialize`). Панели хоста — в Debug последними

## Р2. Bloom (2026-09-26, M)

- **Сделано.** `Renderer.Bloom` (`BloomSettings`: вкл, интенсивность 10, порог 1 — уровень LIVE-2 с факелом), `BloomKernel` (числа UE, CPU-эталон
  ядра), `BloomChain` — 18 проходов `post.bloom.*` в Post перед тонмапом, тонмап — (сцена + bloom) × экспозиция. Без HDR или с неактивным bloom
  проходов нет, тонмап прежний. Сэмплер s3 `gLinearBorder` (за краем чёрный).
- **Как в UE 5.8** (по коду BloomSetup, WeightedSampleSum, Downsample, `PostProcessBloom.usf`, `PostProcessTonemap.usf`; текст не переписан): порог на
  ½ после уменьшения; цепочка ½…1/64 — среднее блока 4×4 (4 билинейные выборки, качество High); ступень s — на уровне s, от широкой (1/64) к
  узкой: по x, затем по y × оттенок · интенсивность / 6 (в UE `TintScale` = Intensity / 6 — в исследовании §3.10 не отмечено) + сумма более широких
  (билинейно); R = ширина уровня · Size · 4 · 0.005, веса exp(−16.7 (x/R)²) парами билинейных выборок, нормированы; за краем — чёрный; bloom —
  к сцене до экспозиции. Сумма усилений при 10 — 1.325.
- **Иначе и почему.** Предел радиуса 127 текселей (UE по умолчанию 31 — с ~1550 px две широкие ступени перестают расти с экраном); без «fast blur»
  (как качество Epic); порог и уменьшение до ½ — один проход; веса считает шейдер (корневых констант 28, таблица не влезает); вход порога и выход
  ступени зажаты в предел half (NaN → 0, бесконечность сцены не делает bloom бесконечным); без cross, dirt mask, локальной экспозиции.
- **Числа.** GPU 1280×720 (RTX 5070, кадр арены): bloom 0.053 мс на 18 проходов (setup и y2 — по 0.006), тонмап 0.025 (было 0.023), кадр 0.51.
  Дневная арена: максимум входа тонмапа 1.08–1.18, ярче 1 — 0.0004–0.01 %; после среднего 4×4 всё ниже порога — добавка 0, кадр с bloom и без —
  байт в байт (`ArenaBloomGpuTests`). Пятно 8×8 со 100 в центре 512²: энергия гало 0.995 × 1.325 × энергия пятна (край широкой ступени), разброс
  по кругу на 5–30 % ширины ≤ 2.1 %, интенсивность 20 / 10 — 2.0000, 1280 → 1920 — гало на 3–45 % ширины ±2.6 %; кадр 0 Б.
- **Агентские инструменты:** `HdrCapture.Bloom` (настройки, максимум и среднее добавки × экспозиция, NaN), `FrameCapture.BloomPath` — карта добавки
  в шкале `.hdr.png` и сырой half; `--shot` — `.bloom.png`/`.bin`, `--json` — `report.hdr.bloom`, `.shot.bloom`; `capture.bundle` — `hdr.bloom`;
  `render.graph` — `bloom`; `SWORD_TEST_KEEP=1` — снимки `BloomGpuTests` не удаляются. Хватает: тесты читают добавку из снимка.
- **Отклонения.** Выключить bloom у `Sword.exe` нельзя (ручки — Р6): вкл/выкл на арене — GPU-тестом игры. `AGENTS.md` Render — 3 строки (bloom, s3).
  В `HdrGpuTests` bloom выключен. **На приёмке:** README/`AGENTS.md` Render, playbook (bloom); глазами — гало огня (~10), сверить с LIVE-2.
- **Проверка (исполнитель Р3).** Дифф против задания сходится: порог saturate((L·экспозиция − порог)·0.5) на ½ после среднего 4×4, шесть
  ступеней 0.3/1/2/10/30/64 % × 4 на уровнях ½…1/64, веса exp(−16.7 (x/R)²), оттенки × интенсивность / 6, bloom — до экспозиции; размеры
  целей — от графа каждый кадр (ресайз), делегаты — один раз (0 Б). `Sword.Engine.Render.Tests` 55/55, снимки `artifacts/r2` в порядке. Правок нет.

## Р3. Точечный свет (2026-09-26, M)

- **Сделано.** `PointLights` (`Renderer.Lights` = `RenderFrame.Lights`): `PointLight` (позиция, линейный цвет, I, R, `LightFalloff`, дальность показа,
  индекс LF) и `LightFunction` — список на кадр; после построения кадра — отбор по дальности от `ViewOrigin`, первые 64 видимых — в `FrameData`
  (элемент 0 — число), лишние отброшены со счётчиком. `common/lights.hlsli` `PointLightsDiffuse` — множитель альбедо, эталон — `PointLightMath`.
  SRV — строка `FrameConstants.PointLights` игры (b0 видят все проходы сцены; число в буфере — источники можно добавлять после констант).
- **По UE 5.8:** экспонента (1 − saturate(d²/R²))^exp, unitless; обратный квадрат saturate(1 − (d²/R²)²)²/(d² + 1 см²), I — канделы; альбедо/π ×
  N·L × цвет × I; дальность — множитель на CPU (GetLightFadeFactor без угасания по размеру). LF = A.r + B.r → к DisabledBrightness в последних 20 %
  FadeDistance (умолчания UE 1000 м, 0.5) → 0…1; сдвиги по времени — на CPU, мип 0 (шов atan2). UV: UE (x, y, z) = SWORD2 (z, −x, y), после zyx
  u = (atan2(−x, y) + π)/2π, v = acos(z)/π — полюса ±Z, шов вниз; оси источника — мировые.
- **Единицы.** Солнце `Shade` (альбедо × 1.25, без 1/π) = UE-свет π·1.25 ≈ 3.9. Факел (100, экспонента 400, R 20 м): у источника альбедо × 31.8 по
  красному (25 солнц), на полу в 1.4 м под ним × 4.5. Specular нет (отступление: у сцены нет шероховатости, у солнца блика). Свет — после тумана
  как (1 − туман)·p: до `lerp` компилятор давал 1 ULP в одном пикселе без источников, так — бит в бит.
- **Числа.** Арена без источников — HDR-цвет `Sword.exe --fps 60 --frames 40` бит в бит с кадром до точки. GPU `scene.opaque` 1280×720 (бенч, RTX
  5070): 0 — 0.195 мс, 1 — 0.206, 64 факела — 0.827 (кадр 0.275/0.286/0.906). Факел (камера 12 м): красный +0.1 и больше — 3.3 % пикселей, пол
  в 0.8 м +0.34…0.71, синий не меняется. Рендер с 70 источниками и LF — 0 Б; бенч с 64 — 1–2 Б, как без света на GPU-bound 1080p (не от света).
- **Агентские инструменты:** `Sword.exe --test-light [N]` (факел у игрока, N − 1 по кругу 3 м), `--overlay lights` и слой `lights` (крест, круги R
  и половины затухания, подпись), `--json` — `report.lights`, `lightsOverlay`; `render.graph` — `lights`. Хватает: тесты читают сырой HDR.
- **Отклонения.** Пресет факела без дальности (в LIVE-2 12 м, камера арены 24 м); клавиши оверлея нет. **На приёмке:** README/`AGENTS.md` Render,
  playbook (`--test-light`, `lights`); полный прогон (`CorpseClientTests` — `KnownOverlays` с `lights`, не запускался); глазами — факел.
- **Проверка (исполнитель Р5).** Дифф против задания сходится: экспонента (1 − saturate(d²/R²))^exp и обратный квадрат с окном UE, Ламберт /π,
  дальность показа с угасанием на CPU, LF = saturate(·) только в диффузе поверхности, UV по осям UE (x, y, z) = SWORD2 (z, −x, y), 64 источника.
  `CorpseClientTests` 10/10, `Sword.Engine.Render.Tests` 69/69, `artifacts/r3/torch.png` — красное пятно у игрока. Правок нет; мелочь на будущее:
  вклад источников × ao, солнце — без ao (сейчас ao всюду 1).

## Р5. Прозрачная фаза (2026-09-26, M)

- **Сделано.** `BlendMode.Premultiplied` (One, InvSrcAlpha; альфа так же). Проход по HDR-сцене — `Color(SceneColor).Depth(Scene.Depth, Read).Read(Scene.Depth)`:
  граф уже ставил DEPTH_READ | SRV — покрыто тестом (второй такой проход без переходов, GPU-валидация чиста). `gbuffer.hlsli` — `SceneViewDepth`
  (k = `TransparencyMath.ViewDepthParams` проекции: d = k.y / (z − k.x), конечная и бесконечная) и `DepthFade`; CPU-эталон — `TransparencyMath`.
  Слой ½ — `HalfResTransparency` (`Renderer.HalfRes` = `RenderFrame.HalfRes`, `common/halfres.hlsl`): `Begin(k)` — проход `transparent.halfres.depth`
  (глубина ½ D32 + цель ½ RGBA16F, очищена нулём), проходы вызывающего в `HalfResTarget.Color`, `Composite()` — `transparent.halfres.composite` в
  `SceneColor`; раз за кадр, только с HDR, `Begin` без `Composite` — исключение. Дым — между ними, пламя — после (порядок регистрации фазы).
- **Решения.** Глубина ½ — ближайшая в блоке 2×2: марш не проходит сквозь передний план, у персонажа не бывает дыма из-за него; фон у силуэта
  находит соседа со своей глубиной, а не нашёл — недобирает дым на пиксель (светлый контур вместо ореола). Апсемпл — 4 билинейных соседа ½,
  согласованные по линейной глубине (|Δ| ≤ 5 % глубины пикселя, `DepthTolerance`) с перенормированными весами; все — ровно билинейный; ни одного —
  ближайший по глубине. ½ = ⌈n/2⌉, центр пикселя в текселях ½ — x/2 − ¼.
- **Числа.** GPU 1280×720 (RTX 5070, без отладочного слоя): уменьшение глубины 0.012 мс, композит 0.047 мс. Край (67×41 → 34×21, столбцы 7/3/1 px и
  полоса строк, 5 м на 50 м): 496 пикселей переднего плана без цвета фона (≤ 10⁻³), 2251 фона без переднего; чистый билинейный на той же сцене —
  ореол ≥ 0.1 (контроль теста). Ровное — билинейный ±2·10⁻³; «поверх» — формула ±2·10⁻³ по HDR; мягкий край — эталон ±3·10⁻³, за стеной — 0.
  Размеры 1×1 … 101×55 и смена — без ошибок; 0 Б на кадр. Игра (прозрачного нет): HDR и цвет `--no-hud` бит в бит с `artifacts/r3/after0`.
- **Агентские инструменты:** `FrameCapture.TransparentPath` → `HdrCapture.Transparent` (размер ½, яркость × экспозиция, покрытие — средняя альфа,
  NaN; карта шкалы `.hdr.png` и сырой half); `--shot` — `.transparent.png`/`.bin` (если слой в кадре), `--json` — `report.hdr.shot.transparent`;
  `capture.bundle` — `hdr.transparent`; `render.graph` — `transparent.halfres.*`. Хватает: тесты читают сырой half; снимки — `artifacts/r5`.
- **Отклонения.** Слой ½ один на кадр (общий для модулей — по вызову `Begin`/`Composite`); допуск — доля глубины, не по её наклону; слой снимка —
  цель ½, а не вклад всего прозрачного. `AGENTS.md` Render — строка контракта. **На приёмке:** README/`AGENTS.md` Render, playbook
  (`.transparent.png`, `hdr.transparent`); глазами — на огне (контур у силуэтов, допуск 5 %).
- **Проверка (исполнитель Р4).** Дифф против задания сходится: One/InvSrcAlpha для цвета и альфы, композит — DEPTH_READ | SRV глубины сцены,
  глубина ½ — максимум блока 2×2 (обратный Z — ближайшая) с краем нечётного кадра, ⌈n/2⌉, апсемпл — 4 соседа (веса ¾/¼), согласие |Δ| ≤ 5 %
  глубины пикселя, иначе ближайший; делегаты — один раз (0 Б). `Sword.Engine.Render.Tests` 75/75. Правок нет.
