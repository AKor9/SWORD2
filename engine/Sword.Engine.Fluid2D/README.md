# Sword.Engine.Fluid2D — ядро 2D-сима жидкости

Порт 2D-сима FluidNinja LIVE-2 (`NinjaLiveCore`) на рендер-граф: гриды, кисть, стадии шага на GPU, CPU-эталоны, статистика и снимок. Общее
для эффектов, которые различаются только параметрами: потребитель — модуль огня `Sword.Game.Fire.Client`; режим крови на полу —
пресет `Fluid2DParams.Blood` со сдвигом окна целыми текселями, каналом возраста и штампами (раздел «Режим крови»); режим песка есть в
`Fluid2DParams`, потребителя у него нет; кровь, которая растекается и течёт по уклону, — пресет `Fluid2DParams.BloodSpread` (раздел «Плёнка»).
Игру не знает. Формулы и числа — `artifacts/research/fluidninja/fire-smoke-research.md` (FSR) §3.2–§3.6 и `brush-research.md` (BR) §3–§4, §6, §8.2, §9
(решения пользователя 3: «порт формул и чисел L2 с записанными отступлениями» и 11: детерминированная кисть BR §8.2 с решениями (a)–(e) по
рекомендациям). Правила — [AGENTS.md](AGENTS.md), история — [docs/history/stage-f.md](../../docs/history/stage-f.md).

## Устройство

**Гриды** — хранилища `GpuStorage` в битах half (раскладка RGBA16F, ряд за рядом, ряд 0 — v = 0):

| Грид | Тексель | Кто пишет | Смысл |
|---|---|---|---|
| C (composite) | 4 half | Composite | (vx, vy, ρ, wet) — состояние шага, его экспортирует `RT_Composite` |
| A (advected) | 4 half | Advection | (vx, vy, ρ) ×VelocityFeedback; wet — копия C того же текселя (Composite читает прошлую мокрую карту из A) |
| P, S (pressure0/1) | 2 half | Divergence, Pressure | (P, D); итог давления — в P, буферы меняются ролями после двух проходов |
| кисть (brush0/1) | 8 half (`Fluid2DBrushTexel`) | Painter (или вызывающий — `Step(…, GpuStorage)`) | слои PainterGrid: 0, 1 — скорость, 2 — плотность, 3 — 0, 4–6 — битмап; (N / PaintBufferDownScaleFactor)²; два буфера меняются ролями |
| Ec, Ea (age) | float | Composite, Advection | возраст, с — только при `AgeChannel` (после Composite и после адвекции) |
| штампы | float | `fluid.stamp` | плотность штампов шага; создаётся при первых штампах, Composite читает только в шаге со штампами |
| ρC, ρA (density) | float | Composite, Advection | ρ — состояние при `ConservativeDensity` (канал z C и A — его копия в half для экспорта и статистики) |

Выборка — вручную по `Load`: билинейная с зажимом у края (clamp-сэмплер L2) и ближайший тексель там, где L2 читает `ld`; шумы — билинейно
с заворотом, мип 0, канал r (sRGB декодирует чтение текстуры). Так GPU и CPU считают одну арифметику float (шейдеры симуляции — `-Gis`, без
FMA) и совпадают до округления в half.

**Шаг** (`Step(RenderFrame, in Fluid2DStepInput, Fluid2DBrush, Fluid2DStamps? = null)` или с готовым гридом кисти `GpuStorage?`) —
вычислительные проходы фазы `Simulation`, 8×8 потоков: `fluid.painter` (кисть, ниже) → `fluid.stamp` (штампы шага, раздел «Режим крови») →
`fluid.composite` (A в uv + WOD, проекция прошлым давлением, ввод кисти,
постоянный ввод × amp-шум, направленный шум-симплекс, зажим, упругость края, плотность × накопление × маска края, мокрая карта) →
`fluid.advection` (uv − v·SimSpeed/N) → `fluid.divergence` (±SimSpeed текселей, прокол кисти, P прошлого шага в uv + WOD) →
`fluid.pressure.x` → `fluid.pressure.y` (ядра 15/13/11/9/7/5 тапов через SimSpeed текселей, 16 выборок, веса L2) → `fluid.stats.rows` →
`fluid.stats`. Грубый решатель — один проход давления, X/Y по чётности шага. При `DivergenceMult` 0 (`HasPressure` false) дивергенция
нулевая, и шаг идёт без `fluid.divergence` и `fluid.pressure.*` (сим и эталон): поле давления остаётся каким было — после очистки нулём,
Composite проецирует нулевым давлением бит в бит так же. Первый шаг после
`Reset()` начинается проходом `fluid.clear` (и `fluid.painter.clear` у кисти). Формулы — `Shaders/fluid2d/fluid2d.hlsl`, `Fluid2DReference`,
`Fluid2DPainterReference`.

**Вход шага** `Fluid2DStepInput`: номер шага (время шумов t = Step × `StepSeconds` — по номеру, не по часам кадра), `WorldOffset` (шумы
привязаны к миру), `WorldOffsetDelta` (сдвиг площадки за шаг в UV, FSR §3.6 — считает вызывающий), поворот площадки (для `DirectVelocity` в
мировых осях), `VelocityOffsetDelta` (инерция площадки), `ShiftTexels` (сдвиг окна целыми текселями: тексель x гридов прошлого шага —
A, P, кисть, возраст — берётся из x + сдвиг (после зажима у края) точной копией, вне прежнего окна — 0; шумы двигает `WorldOffset`). Числа шага, общие для GPU и CPU, — `Fluid2DConstants` (элемент
`FrameData`, до `MaxStepsPerFrame` = 64 шагов за кадр): постоянные части координат шумов берутся по модулю 1 в double, веса ядра — по
`KernelMult`/`KernelIndexOffset` как у L2 (ряды через 15, 16 весов, вне таблицы — 0).

**Выход** — `Export(RenderFrame)` → временная текстура RGBA16F N² кадра (`fluid.export`, раз за кадр после шагов): (v·edge10, ρ^Contrast
или 1 − ρ^Contrast, max(wet·маска·edge10, 0.01) или 1 − ρ^Contrast). Выборку (clamp, билинейную) делает материал. Возраст —
`ExportAge(RenderFrame)` → временная R32F N² (`fluid.export.age`) или хранилище `Age` (float на тексель, как `Composite`).
Состояние между шагами (выход Advection, вход Composite следующего) — `Advected`, `AgeAdvected`, `DensityAdvected` (ρ во float при
`ConservativeDensity`): вызывающий может вынуть массу проходом до шага (кровь — засохшее в карту пятен), обнулив ρ текселя во всех трёх.

**Шум скорости** — `SimplexNoise` (C#) = `Simplex2` (HLSL): 3D-симплекс по открытому описанию (Gustavson; углы — сравнением координат, McEwan
и др.), вклад угла (1 − 2|f|²)³·1024/375·(g·f), градиенты (±1, ±1, ±1) из битов 15–13 хеша PCG3D (Jarzynski, Olano) координат угла ×6,
завёрнутых с периодом 300 — те же шаги, что `JacobianSimplex_ALU` UE (FSR §3.4); отличие — порядок операций float, якобиан не считается.

**Статистика** — редукция в фиксированном порядке без атомиков (группа на 8 рядов, дерево в groupshared, затем группы по порядку): шаг,
Σρ, max|v|, max ρ, Σwet, тексели с Inf/NaN, центроид ρ (UV) — 64 Б в `StatsStorage`, разбор `Fluid2DStats.Parse`. Асинхронно —
`Renderer.CreateReadback` / `GpuSimContext.Readback` (задержка 3 кадра); синхронно — `ReadStats()`; по полю на CPU — `Fluid2DStats.Compute`.

**Вне кадра** (ожидание GPU; тесты и снимки): `ReadFields()` / `Load(Fluid2DFields)` — все четыре грида в half, `ReadBrush()` / `LoadBrush` —
грид кисти, `Snapshot()` → `Save(prefix)`: `.density.png` (ρ), `.velocity.png` (vx, vy вокруг 0.5 в пределах ±VelocityClamp; B — wet), `.bin`
(N × N × 4 half C); если был Painter — `.brush.density.png`, `.brush.velocity.png` (±BVC·VMXY; B — слой 6), `.brush.bin` (BN × BN × 8 half).

**Контракт шейдеров** — `Fluid2DSim.Contribute(ShaderContract)` (размер констант, слоты `gFluid*`, числа потоков); модуль вызывает его через
`ClientBuilder.Shaders`.

## Кисть

Детерминированная кисть BR §8.2: CPU готовит точки шага, GPU рисует грид кисти (N/2) одной формулой для всех точек и сливает мазки без
зависимости от порядка. Общая для огня, крови и песка: источники и числа — параметрами.

**CPU — `Fluid2DBrush`** (шаг: `Begin(input, tickId, центр площадки, камера?)` → `Add(ключ, мир м, s, флаги)` ×n → `End()`):
- Ключ `Fluid2DBrushKey` = (класс источника `Array`/`Particle`/`Debris`, id сущности, индекс кости/сегмента); прошлая позиция, UV и UV-скорость
  хранятся по ключу. Новый ключ, ключ, которого не было в прошлом шаге, и `Forget(ключ)` (пересоздание, у факела — `WeaponTip.Built`) — без
  отрезка, V = 0; смена состава остальные точки не трогает. `Reset()` — активация: Age = шагов с неё × StepSeconds; V = 0 при Age < 0.25 с
  (15 шагов), отрезок — при Age > 0.25 с, прокол нарастает sat(0.1·Age) — полный с 600 шагов.
- UV: W2U = diag(1/E)·R⁻¹·(P − центр) + 0.5 (x — u, y вверх — v убывает, z вдоль нормали ÷ max E); у площадки к камере (`CameraFacing`) с
  камерой — перенос на глубину центра P′ = Cam + (P − Cam)·d_c/d_P, z = (d_c − d_P)/max E + 0.5. V = Δp/StepSeconds; UV-скорость — 0.1·(R⁻¹V)/E
  у CF (факел 3 м: 1 м/с → 0.0333), 0.05·R⁻¹V у мировой площадки — одна шкала для всех классов (решение (c)); упреждения нет.
- Джиттер (только `Array`): (hash(зерно, TickId, ключ) − 0.5)·20·BPR см по каждой оси (SplitMix64, 24 бита), ×min(5|UV.xy|, 1) при
  `BrushRndScaledByVelocity`. Отрезок (решение (a)): у CF и экранных точек prev — прошлая позиция точки с её джиттером (палочка ≈5 см у
  движущегося факела), у мировых — прошлая мировая позиция в текущих осях площадки, без джиттера.
- Числа точки, не зависящие от текселя (`Fluid2DBrushPoint`, 20 слов): проверка скачка |ΔUV| ≥ 1 (массивы), вес ABV/PBV, зажим, толчок
  sign·|vc|^Pow, растяжение и K, отрезок, прокол pz, kv, str0, strp, жёсткость, FadeZ, AABB штампа ±4σ·stretch.
- Отбор: экранная точка — всегда; иначе |z_лок| ≤ Ez/2 и AABB штампа ∩ площадка (решение (e): точка за краем оставляет полумазок); за камерой —
  отсеяна. Сверх `BrushMaxPoints` остаются меньшие ключи («отброшено»). Точки сортируются по ключу.
- Бининг (решение (d)): ячейка — m×m тайлов 8×8 текселей (тайл = группа Painter), m ≥ радиуса 4σ·stretch в тайлах, не больше 32 ячеек по оси;
  записей больше `BrushMaxEntries` — ячейки вдвое крупнее (переполнения нет). Слово ячейки — начало | число << 16; в ячейке — порядок ключа.
- Кадр — 0 Б после прогрева. Для наблюдения: `Points` (ключ, голова и хвост в UV, UV-скорость, s, σ см, есть ли отрезок), `Stats` (добавлено,
  осталось, отсеяно, отброшено, записей, ячейка в текселях).

**GPU — `fluid.painter`** (`CsPainter`, тексель грида кисти; шаг кисти — слова в `FrameData<uint>` кадра, буфер растёт при новом максимуме):
шумы текселя по `T_NoiseTemplate2` (RG — скорость: 0.1·BVN·(RG − 0.5) в (uv + WO)·Scale + t·Freq; R — плотность: max(1 − BDN, R^Pow) в
(uv + WO)·Scale + floor(t·Freq)·0.1; без `BrushNoiseInWorldSpace` — 0.5·uv), затем точки ячейки текселя с AABB, содержащим тексель: формулы
ветки i = 0 L2 (BR §4.2) — f (штамп и отрезок, exp2), радиальный член (vnz + a)·100·pz·(1 − f)²·(str0 + 1 − k), s_h = smoothstep жёсткости,
заострение при IF > 0.5, velo_i = clamp(sv·vel·mv, ±BVC)·VMXY, dens_i = s_h·strp. Слияние: D — наибольший |dens| со знаком (при равенстве —
меньший ключ), V̄ = Σ s_h·velo / max(Σ s_h, 10⁻⁶), A = sat(D + b), b = (1 − IF)³; сим — Paint = (V̄, clamp(D, ±1))·A² + old(uv + WOD)·(1 − A)
(одна точка — ровно ветка i = 0 L2); painter-режим и `ForceAdditiveStrokeBlending` — Σ мазков ×A^0.25 или ×A. Маска края (w ≤ 0.05 — ступень,
иначе m^0.1) на слоях 0–2; слой 3 — 0; слои 4–6 — битмап как у L2 (RG — скорость, B или R — плотность; нет битмапа — 0). Composite читает
кисть билинейно, Divergence — ближайшим текселем.

Текстуры Painter — аргументы конструктора `Fluid2DSim`: `brushNoise` (`effects/fire/noise_template2.swtex`, слой `T_NoiseTemplate2`, RG8
линейная; нужна при `BrushNoiseUsed`) и `bitmap` (RGB; нет — слои 4–6 = 0); выборка — билинейная с заворотом, мип 0.

**Эталон** — `Fluid2DPainterReference` (те же выражения и порядок float; `fullScan` — все точки без бининга и отсечения, для проверки (d)).

**Параметры кисти** (`Fluid2DParams`, умолчания — факел BR §7.2 с поправками §9): `Extents` (3, 3, 3) м, `CameraFacing`, BPR 0.5 (флаг
масштаба выкл.), `BrushSize` 1, `BrushStrength` 1, жёсткость 0/0, Kill 0, SK 0, FadeZ выкл., шум плотности 0.05/3/40/2, шум скорости
0.5/0.1/30, VMXY/VMZ 1/1, Pow 1.6, BVC 2, ABV/PBV 1/1, `PosInterpolation`, KillInterpolator 10, IF 0.2, `PainterEdgeMaskWidth` 0.05, битмап
(`DensityTxt*`, `UseInputTextureOnlyAsDensity`), `BrushMaxPoints` 64, `BrushMaxEntries` 1024. `BrushPuncture` общий с Divergence. s источника —
`Fluid2DBrush.PrimitiveScale` (0.07·R·множитель; шишка факела R 2.35–2.5 см, ×2 → s 0.33–0.35, σ 3.1–3.3 см) и `BoneScale` (0.05·длина).
Кисть и сим — с одними параметрами (проверяется на шаге).

## Режим крови

Вязкая кровь на полу — B1 LIVE-2 (BVR §2.2, §2.3, §2.7) в мировых единицах на сетке SWORD2 (BVR §6.8 с BR §9.2). Новые механизмы — флагами и
входами шага; у огня они выключены, его поля и экспорт — бит в бит прежние.

**Пресет `Fluid2DParams.Blood`**: горизонтальная площадка (`CameraFacing` false), `Extents` 32×32×0.65 м (полоса отбора кисти — как у BD),
N 1024 (тексель 3.125 см), кисть без огрубления (`PaintBufferDownScaleFactor` 1: σ стопы 4 см меньше текселя 6.25 см грубой кисти), SimSpeed 3
(d = 9.4 см), 60 Гц; VF 0.9, DA = 2/0.9 − 1 (нейтраль: ρ за шаг ×1), VelocityClamp 50, DivergenceMult 0.04, ядро 15 со сдвигом рядов −2
(веса P вне таблицы — давление без памяти), маска давления у краёв; VeloFromBrushMotion 10 × VMXY 4, Kill 0.1 (2 м/с), жёсткость 0.5, шум
плотности кисти 0.4, KillInterpolator 100, IF 0.05, прокол 0, джиттер 0, `DensityTxtMult` 0 (битмапа нет); шум скорости 100 с маской |v|
(Size 0.125 → ячейка 6.25 см, статичен), шум плотности Tile 7 (период 4 м), amp-шум выключен (постоянного ввода нет), упругость края 0
(без рамки столкновений). Полосы краёв — те же метры, что у B1 на 20 м: `EdgeMaskWidth` 0.03125 (50 см, степень 1), `PressureEdgeMaskWidth`
0.09375 (1.5 м), `PainterEdgeMaskWidth` 0.15625 (2.5 м, мягкая). Выбрано без данных BVR: `WetMapEdgeMaskWidth` 0.0625 (те же метры, что 0.1
на 20 м; у B1 не сверено; кровь пола мокрую карту не рисует), `Extents.Z` 0.65 м (полоса отбора кисти; у крови пола кисти нет — штампы), `DensityFloor` 0 (у L2 1e-6: чистый ноль — пустой пол без массы, возраст 0), `BrushMaxPoints` 256 / записей 4096.
Память 1024²: C, A 8 МБ, P, S 4 МБ, возраст 8 МБ, кисть 2 × 16 МБ, штампы 4 МБ — 68 МБ.

**Округление half** (`HalfRoundToNearest`, у крови вкл.): `f32tof16` железа режет к нулю, и при нейтральном DA лужа в покое теряет 0.26 % за
600 шагов (тексель уходит до 8 ULP, затем стоит); C и A крови пишутся с округлением к ближайшему (как `(Half)` эталона) — 0.0002 %, ≤ 1 ULP.
ρ во float32 не понадобился.

**Сдвиг окна** — `Fluid2DStepInput.ShiftTexels`: Composite читает A, P, возраст, Divergence — P, Painter — прошлую кисть через сдвиг
(у кисти — сдвиг / огрубление, кратность проверяется). При v = 0 и сдвиге туда и обратно поля совпадают байт в байт с шагами без сдвига.

**Возраст** (`AgeChannel`) — два грида float (с): Composite берёт возраст A в той же точке, что ρ, с весом ρ (Σw·ρ·age / Σw·ρ), прибавляет
`StepSeconds`; приток (ρ выше, чем дала бы старая кровь: sat(ρ_A)·накопление·маска) омолаживает: age' = (age + dt)·ρ_старая/ρ_новая; где ρ = 0 —
0. Адвекция переносит его той же билинейной выборкой с весом ρ. Float, а не half: в half секунды выше 64 с перестают расти (ULP > dt).

**Штампы** — `Fluid2DStamps` (`Begin(шаг, центр, поворот)` → `Add(мир, угол, полуоси м, объём ρ·м², форма)` или `AddUv` → `End()`, затем
`Step(…, stamps)`): CPU сортирует штампы по словам записи (сумма не зависит от порядка добавления), отсекает вне площадки, бинингом раскладывает
по ячейкам 8·m текселей (≤ 32 по оси; записей больше предела — ячейки вдвое крупнее); `fluid.stamp` суммирует в тексель штампы его ячейки в
этом порядке, без атомиков; Composite прибавляет грид к ρ после множителя накопления (×маска края) — масса C растёт ровно на объём.
Форма 0 — гаусс: σ = полуось/2, не меньше 0.75 текселя (сумма по текселям = интегралу), обрезка на 4σ, пик = V/(2π·σx·σy·(1 − e⁻⁸)). Форма
k ≥ 1 — канал r слоя `Layer + k − 1` текстуры форм (`stampShapes` конструктора сима; эталону — картинки слоёв) на прямоугольнике ±полуоси,
пик = V/(4ab·среднее слоя), среднее даёт вызывающий. Толщину на единицу ρ выбирает вызывающий: ρ_A выше 1 следующий шаг обрежет.

## Плёнка (A′)

Кровь как плёнка в том же ядре (BVR §5.2, §7 «A′»): масса сохраняется, ρ — толщина, толстое течёт, тонкое стоит, лужа растекается до своей
толщины и стекает по уклону рельефа. Всё — флагами `Fluid2DParams`; без них стадии — бит в бит прежние (хеши полей огня, «всех режимов» и
крови после 60 шагов с кистью, штампами и сдвигом — те же, что до плёнки).

- `ConservativeDensity` — Advection переносит ρ потоками через грани (донорская схема: скорость грани — среднее двух текселей, поток берёт ρ
  стороны, откуда течёт; у края грида — стенка) вместо полулагранжевой выборки, без ×VelocityFeedback; оба текселя грани считают одно число,
  поэтому масса, ушедшая из одного, ровно пришла в другой. ρ хранится во float (гриды ρC, ρA): в half медленный поток между текселями разных
  порядков округлялся несимметрично (−8.6 % за 10 000 шагов в чаше), во float — 0.0000 %. Возраст — те же потоки × возраст донора. Скорость —
  прежней выборкой; Composite зажимает компоненты по CFL: |v|·SimSpeed ≤ `FilmCourant` (0.25 текселя за шаг, сумма по граням ≤ 1 — ρ ≥ 0).
- `UnboundedDensity` — без `saturate` ρ ≤ 1 (только ρ ≥ 0): толщина h = ρ·`FilmThicknessPerDensity` (h_max, 3 мм на ρ = 1).
- `FilmFlow` — в Composite после ρ: тоньше h_min (`FilmMinThickness` 0.3 мм) — v = 0 (мазок стоит бит в бит); иначе
  v ← (v − g·dt·∇S)/(1 + k·dt/h²), S = рельеф + `FilmSpread`·max(h − H, 0): трение Пуазейля неявно (`FilmFriction` k = 1e-4 м²/с;
  у настоящей крови 3ν ≈ 1e-5 — плёнка 1 мм на 17° бежала бы 30 см/с), растекание собственным весом — только от избытка над толщиной лужи H
  (`FilmPuddleThickness` 1 мм), соседи h — из A через сдвиг окна, центральная разность. Установившаяся скорость на уклоне — g·tanα·h²/k
  (tanα, а не sinα: уклон — градиент высоты; на 17° +4.6 %). `FilmSpread` (10 у пресета) ускоряет выход лужи на H, не меняя скорость на склоне.
  `FilmGravity` — g, м/с².
- Высоты рельефа — `Fluid2DSim.Heights` = `Fluid2DHeightField(Srv, Cells, Half)`: `StructuredBuffer<float>` узлов (Cells + 1)² по рядам z на
  ±Half м (форма `ITerrainView.HeightsSrv` и `Grid`), рельеф билинейный по ячейке, вне сетки — крайняя ячейка; уклон — точный градиент
  билинейной поверхности в текселе. Окно горизонтально (u — вдоль +X, v — вдоль +Z, поворот −90° вокруг X), его мировой центр —
  `Fluid2DStepInput.WindowCenter`. Нет высот — уклон 0. Эталону — `Fluid2DReference.Heights` = `Fluid2DHeightImage`.
- Источник — штамп (`Fluid2DStamps`) каждый шаг: прибавка массы без порога Kill (лужа под лежащим трупом).

**Пресет `Fluid2DParams.BloodSpread`** = `Blood` + три флага, `FilmSpread` 10, VelocityFeedback 1 (гасит трение), DensityAccumulation 1
(множитель накопления ровно 1 — масса только из кисти и штампов), DivergenceMult 0 (растекание — дивергенция; проходов давления нет, P = 0). Числа (тесты 256², тексель 3.125 см): лужа 0.2 л — ⌀ 0.39 м за 0.5 с, 0.45 м за 3 с, встаёт за ~20 с на ⌀ 0.51 м (площадь
объём/H + 1.6 %); на 17° плёнка 1 мм — 2.7 см/с, 0.5 мм — 0.71 см/с (формула 0.75), 0.2 мм стоит; постоянный источник 25 мл/с — площадь
×1.77 и ×2.13 за удвоение времени (4 → 8 → 16 с), после перекрытия лужа встаёт на объём/H + 3.5 %. Память 1024² сверх `Blood` — ρC, ρA 8 МБ.

## Отступления от LIVE-2

- Гриды — хранилища half с ручной выборкой, а не текстуры Niagara с аппаратным сэмплером: нет 8-битной дробной части весов железа, GPU = CPU.
- Давление: тапы ровно в текселях (у L2 позиция `j − dir` — сдвиг ≈0.011 текселя); тап за краем u = 1 или v = 1 (правым и нижним на экране)
  — крайний тексель (у L2 clamp в [0, 1] и `frac` переносят его на противоположный край: у самого края до 41 % весов P и 55 % D — из
  текселей u = 0 или v = 0).
- `DirectVelocity` — вектор в мировых осях вызывающего и поворот площадки (x — u, y — вверх, z — нормаль): in = (l.x, −l.y); у L2 —
  q⁻¹·(X, Y, −Z) в осях UE. Числа факела переведены в оси SWORD2. При наклонной площадке у L2 (из-за −Z) горизонтальный ветер вдоль
  взгляда входит в подъём с обратным знаком; здесь — честная проекция.
- Время — номер шага × `StepSeconds` (у L2 — время движка `cb0[4].x`); постоянные сдвиги шумов — по модулю 1 в double.
- Мокрая карта Composite берётся из A (копия C того же текселя) — то же, что прошлый C у L2.
- Экспорт — каждый кадр из C (у L2 — раз за шаг; содержимое то же).
- Кисть (BR §8.2, §8.3): одна формула (ветка i = 0) для всех точек и слияние по ключу вместо веток i = 0 / i ≥ 1 и наложения в порядке
  атомиков — у одиночной точки то же, у перекрытий значение не зависит от порядка и нет швов ячеек; «вторые» точки толкают s_h, а не f;
  толчок sign·|vc|^Pow покомпонентно, как у L2. Ячейки хеша L2 (1 м, «2 ячейки + r», ≤ 256 точек) заменены бинингом по σ с отсечением
  по AABB ±4σ·stretch (отличие от перебора всех точек ≤ 10⁻³). Упреждения нет (L2: 0.03·Off с — компенсация задержки массивов на шаг;
  факел Off 1 — 1.2 кадра): мазок на месте, без «проскока» на остановке. Джиттер — хеш (зерно, TickId, ключ), а не PCG слота; по Y делится
  на E.y (у L2 обе оси — на E.x; на квадратной площадке одно и то же). Точка за краем не отбрасывается целиком (решение (e)). Единицы
  частиц и обломков — те же, что у массивов (у L2 ×(2, 2, 1) и без 0.1 при CF; решение (c)); хвоста U − 0.01·UV у обломков нет — prev
  настоящий. Age — шаги с активации кисти, время шумов — номер шага; floor(t·Freq) узора плотности — в double с запасом 10⁻⁹.
- Кровь: возраст, штампы и сдвиг окна целыми текселями — своё (у L2 площадки крови неподвижны); C и A крови — half с округлением к ближайшему
  (у Niagara — формат грида); `DensityFloor` 0 вместо 1e-6.
- Плёнка (A′) — своё, эталона в L2 нет: консервативный перенос, толщина без потолка, трение Пуазейля и пороги h_min, H вместо постоянного VF;
  уклон — от буфера высот рельефа на всём окне (у L2 режим B0 — карта сцен-захвата одной площадки и масса-высота 0.955·M + 0.1·ρ, BVR §2.5).
- Не перенесено: `VelocityOnlyInputTexture` (VeloRotate, VeloInputTile, MaskInputWithSimVelocity), текстура маски столкновений, SDF/RVT/
  высоты/сплайны (слои 7–10 захвата; у кисти FadeZ — от плоскости, слой 3 — 0), режим без `SimAreaClamp` (заворот), `ClampHeightLowerValues`,
  `ScaleInvariance`, RT другого размера, чем грид; чтение частиц Data Channel и обломков Chaos (точки этих классов даёт вызывающий), луч мыши
  (экранная точка — готовая мировая позиция), квадратный тексель — только квадратная площадка.

## Ограничения

- `WorldOffset` — float: координаты симплекса (uv + WO)·128·0.5/Size теряют точность при |WO| ≳ 10³ UV (3 км площадки 3 м).
- Не больше 64 шагов за кадр; `ReadFields`, `Load`, `ReadBrush`, `LoadBrush`, `Snapshot`, `ReadStats` ждут GPU — только вне кадра.
- Кисть: точек на шаг ≤ `BrushMaxPoints` (≤ 4096), записей бининга ≤ 65535 (слово ячейки 16:16); круглый мазок — только при квадратной
  площадке (`Extents.X = Extents.Y`, грид квадратный).
- Штампы: ≤ 65535 на шаг и записей бининга ≤ 65535 (слово ячейки 16:16); форма k ≥ 1 — только при текстуре форм у сима.
- Сдвиг окна у грубой кисти — кратен `PaintBufferDownScaleFactor`.
- Плёнка: скорость при консервативном переносе ≤ `FilmCourant` текселя за шаг (0.47 м/с у крови) — толчок кисти сильнее зажимается;
  центральная разность не видит шахматного узора h (его гасят трение и диффузия донорской схемы); лужа выходит на H асимптотически (скорость ∝
  избытку); высоты — только для горизонтального окна.
- Декод sRGB железом отличается от формулы до ~0.004 (тесты сверяют сим на значениях шума, прочитанных с GPU).
