# Sword.Engine.Content — правила

Запечённый контент: пак `.swpak` (`PakFormat`, `PakSource`, `PakWriter`), каталог (`DirectorySource`), контент в памяти
(`MemorySource`, тесты), пути контента (`ContentPath`), поиск пака (`ContentLocator`). Формат пака — из SWORD 2eab13b
(`Sword.Content`).

- Путь контента — относительный, через «/», без «.», «..», пустых сегментов, «:» (диск, поток NTFS), управляющих
  и запрещённых в Windows символов (`ContentPath.Normalize`). `DirectorySource` дополнительно проверяет, что итоговый
  путь лежит под корнем. Любой новый источник контента нормализует путь тем же `ContentPath`.
- Поиск в контенте — без учёта регистра. Кто кеширует ассеты по пути, кеширует по нормализованному пути без учёта
  регистра (как `SkinnedMeshes.LoadMesh`).
- Игра читает только пак; каталог россыпью — инструментам и тестам. Путь в паке = путь в `Content/` (пак собирает
  менеджер ресурсов `tools/Sword.Assets` из игровых ресурсов, их печёт пекарня `tools/Sword.Bake`).
- Потоки контента читаются точным числом байт (`ReadExactly`): `Stream.Read` вправе вернуть меньше запрошенного.

`PakSource.ContentHash` — отпечаток содержимого по оглавлению (пути и хеши файлов): перевыпечка тех же файлов — тот же
хеш. Файлы не читаются. Его несут квитанции агента и реплеи (реплей с другим хешем не сверяется).

`ContentLocator`: `SWORD_CONTENT` → ближайший `Content.swpak` вверх от exe; нет — ошибка с подсказкой
`ContentLocator.BakeHint`.

Проверка: `tests/Sword.Engine.Content.Tests` (пак, пути, выход за корень, хеш контента).
