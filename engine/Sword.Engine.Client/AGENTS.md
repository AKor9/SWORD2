# Sword.Engine.Client — правила

Клиент движка (раздел 7 ARCHITECTURE_PLAN.md): окно → тики симуляции → кадр → показ. Создаёт `Renderer` сам, окно и
`Simulation` получает от exe; клиентской части игры (`IClientGame`) отдаёт только `Renderer` и `SimulationLink`.

- `SimulationLink` — мир только для чтения (`WorldReader`), `Accepts<T>`, команды на ближайший тик, время тика; создаёт
  его только клиент движка. Из его публичных сигнатур не должен быть достижим ни `World`, ни `Simulation`, ни запись
  колонок, а обобщённые параметры его методов — только `unmanaged`
  (`PublicSurfaceTests.SimulationLink_ReachesOnlyReadOnlyWorld`).
- Тики кадра — `SimulationClock` (без окна и GPU): начинает очередь кадра экспорта тика, затем тики — накопитель по
  часам (`Program.cs` SWORD: шаг кадра до 0,25 с, не больше `sim.maxTicksPerFrame`, после упора остаток срезается до
  одного тика) или ровно `ClientOptions.TicksPerFrame` (проверочные прогоны, снимки). Отрицательный и нечисловой шаг
  кадра — ноль.
- Очередь кадра — `SimulationLink.Frame<T>()`: записи экспортированных срабатываний всех тиков кадра с номерами тиков;
  кадр без тиков (в том числе перерисовка при перетаскивании рамки) — пусто. Проверка —
  `tests/Sword.Engine.Client.Tests` (кадры с 0 и 3 тиками через клиент).
- Перед каждым тиком — `IClientGame.BeforeTick`: команды на этот тик (удерживаемое — в каждый тик).
- Кадр, нарисованный из цикла перетаскивания рамки, симуляцию не двигает; его исключение бросается главным циклом.
- Итог прогона (`ClientRunReport`, `--json` у Sword.exe): кадры, служебные кадры, тики симуляции, бюджет обычного
  кадра, проходы рендера, снимок. Перетаскивание окна за заголовок служебным кадром не считается — такой кадр попадает
  в бюджет.
- `Dispose` освобождает игру и рендер, даже если ожидание GPU упало (потеря устройства).

Не сделано (точка 1г): ввод → команды по правилам раздела 7, Extract и `RenderWorld` с интерполяцией по alpha.
Очередь кадра пока никто из игры не читает: экспортируемых срабатываний у ядра нет — первые появятся с Extract.
