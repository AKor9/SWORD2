# Sword.Engine.Platform.Win32 — правила

Окно и ввод на голом Win32 (`Win32Window`). Логика — из SWORD (`AppWindow`), каждое правило ниже когда-то было
ошибкой.

- Ссылаются на эту сборку только exe; остальной движок знает только `IWindow` из `Sword.Engine.Platform`.
- Системные клавиши (`WM_SYSKEYDOWN/UP`) записываются, но отдаются `DefWindowProc`: иначе не работают Alt+F4
  и системное меню.
- Потеря фокуса обнуляет ввод (`ForgetAll`), смена захвата мыши — только уровни кнопок (`ForgetMouse`): фронты
  нажатий кадра должны пережить отпускание захвата после обычного щелчка.
- Захват мыши держится, пока зажата хоть одна кнопка по самому `InputState`, а не по своему счётчику.
- Неактивное окно (`Activate = false`) показывается одним `SetWindowPos` с `HWND_BOTTOM`: показано, но внизу
  и без фокуса. Скрывать его нельзя — DXGI сочтёт окно перекрытым.
- Имя класса окна своё у каждого окна; класс снимается после уничтожения окна.
- Пока тянут рамку, система крутит свой цикл сообщений внутри `PumpMessages`, и главный цикл стоит: `WM_SIZE`
  между `WM_ENTERSIZEMOVE` и `WM_EXITSIZEMOVE` поднимает событие `LiveResize`, по нему клиент рисует кадр.

Логика ввода проверяется тестами `tests/Sword.Engine.Platform.Tests` без окна.
