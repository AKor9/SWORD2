# Бой

Меч в руке у каждого бойца, удар слоем действий (связка, жест, укол), рывок Пробелом, удар ИИ по таймеру, проходы клинка, урон по
частям тела, кровопотеря, смерть, реакции на попадание, возрождение врага через 8 с, статистика арены, причинность (`state.why`), HUD
боя, инвентарь, ручки «Бой» (F3). Мёртвый — труп на физике, меч выпадает (фича
[«Рэгдолл»](../Ragdoll/README.md)), клинок — ещё и тело физики (фича [«Физика и тела»](../Bodies/README.md)), трупы — цели ударов,
удар толкает часть тела. Часть ядра игры (`GameCore`), не модуль. История — журналы, решения, замеры, доказательства перезаписи
эталонов, разборы — [docs/history/combat.md](../../../../docs/history/combat.md).

Код: `game/Sword.Game/Combat/` (мечи и удары, клинок — `BladeSystems`, правила и управление игрока — `PlayerActions`, проходы —
`StrikeSystems`, урон, реакции, кровопотеря, возрождение, статистика — `DamageRules`, `DamageSystems`; `HitImpulse`, `CombatCauses`,
`CombatKnobs`, инварианты), `Animation/` (`AnimatorAction` — слой действий, `Flinch`, `CharacterAssets`), `Ai/EnemyAi.cs`, `Arena/`
(`ArenaCommandSystem`, `ArenaSpawn`); контракты — `Game.Contracts/Combat.cs`, `Damage.cs`; `Game.Data/WeaponMesh.cs`;
`Engine.Geometry/Segments.cs`; клиент — `ArenaView`, `ArenaClient`, `ArenaInput` (`StrikeGesture`), `CombatTuning`, `Hud/Hud.cs`,
`Hud/InventoryPanel.cs`; агенту — `Game.Agent/CombatTools.cs`.

Манифест — [feature.json](feature.json): 18 сценариев (`weapons`, `strike-combo`, `stab`, `run-strike`, `dash`, `strike-from-dash`,
`enemies-swing`, `peaceful`, `duel`, `player-dies`, `bleed`, `respawn`, `dash-through`, `crowd`, `knob`, `hits-to-death`, `tempo`,
`dash-back`), инварианты `combat.*`, `animation.*`, `physics.*`, `movement.rootOverlap`, `locomotion.poses`, `arena.slots`, `ecs.*`;
метрик нет (схожесть со SWORD снята — решение 14); виды `blades`, `strike`, `duel`, `crowd`, `fallen`; бюджеты `crowd`, `crowd-blades`.

## Откуда логика

SWORD 2eab13b — источник идей, а не образец (решение 14). Таблицы «SWORD → SWORD2» — история («Откуда логика (SWORD
2eab13b)»): оружие и клинок — `CharacterRig.TryLoad`/`MakeWeapon`, `WeaponInventory`, `FighterAnimator.Blade`,
`PlaceBodies`; разметка ударов — `ApplySlots`, `StrikeWindows.Find`; удар — `FighterAnimator` (`StartAttack`, `Begin`, `TickActions`),
`PlayerController`, `PlayerAttackPicker`, `EnemyAi.Think`; урон — `DuelArena.KinematicStrikes`, `SweepBlade`, `ApplyHits`/`ApplyHit`,
`Xpbd.SegSeg`; реакции, кровопотеря, возрождение — `KinematicReactions`, `HitReact`, `StartFlinch`, `Fighter.AfterTick`, `DuelArena.Tick`;
HUD, инвентарь, ручки — `Hud.DrawDuel`, `InventoryUi`, `CombatTuning`, `TuningPanel`; идеи — жертва-труп в `KinematicStrikes`, путь
трупа в `ApplyHit`, `HitImpulse`. Рывок — новый (не `Evade` SWORD).

## Устройство

**Стадии** (протокол боя — раздел 9 плана). Begin: `core.prev-transform` → `core.arena-command` (PageUp, PageDown, R, T, «взять меч N»),
`tuning.combat` (ручки). Intent: `core.combat-rules` (смена правил прижимает таймеры игрока) → `core.player-command`, `core.enemy-ai`.
Gameplay: `core.fighter-setup`, `core.body-setup`, `core.blade-setup` (клинок построенного бойца по позе постройки), `core.root-steer`
(курс и разгон с `TurnScale`/`MoveScale`, прибавка рывка), `core.animator-input` (шаг действия). Animation: `core.action-snapshot` →
слои позы (модуль Locomotion) → `core.animator-pose` → `core.animation-tick`. Movement: корень на скорость, у игрока — ещё на прибавку
рывка, затем root motion действия. PrePhysics: `core.kinematic-placement` → `core.blade-placement` (клинок тика). Combat:
`core.strike-detection` → `StrikeContact`, затем пробы. Defense — пусто (блок отложен, решение 16). Resolve: `core.hit-apply` →
`Health`, `Dead`, `Hit`, `SeverRequested`, `HitImpulse`. React: `core.hit-reaction`. Aftermath: `core.bleed`, `core.respawn`. Settle:
`core.arena-stats`. Физика трупов, толчки живых и отдача (`core.kinematic-source`, Physics, `core.root-recoil`) — «Рэгдолл». Экспорт
клиенту и агенту — `Event<StrikeContact>`, `Event<Hit>`, `Event<SeverRequested>`, `Added<Dead>`.

**Оружие и клинок.** Ассеты (`CharacterAssets`): `Weapons` (`WeaponTable` — мечи `weapons/*.swmesh` по имени; клинок по мешу: кончик —
самая дальняя от кисти вершина, основание — `Normalize(tip)·0,22`), `Strikes` (`StrikeTable` — окна урона по кончику, укол — самый быстрый
удар), `Hand` (hand_r); без мечей или кисти игра не стартует. Меч бойца — `WeaponSlot`: враг — случайный меч пака (своя выборка
счётчикового ГСЧ потока `arena.spawn`), игрок — инвентарь `PlayerInventory` (биты мечей, `Equipped`; `combat.playerWeapon`, T — следующий,
«взять меч N»). Клинок — `Blade` (основание, кончик, прошлые; `Weapon` — каким мечом посчитан): постройка — по позе постройки, прошлое =
нынешнему; тик — прошлое — клинок прошлого тика, сменился меч — прошлое = нынешнему; мир — «как показан боец» (как у капсул). Тело клинка
(сегмент 11) ставится вместе с отрезком — «Физика и тела». Клиент: меч — `AddRigid(меш, WeaponWorld)` после всех тел, у трупа — на теле
клинка; оверлей клинков — F7, `--overlay blades`, слой снимка `blades` (игрок — жёлтый, враги — белые, прошлый — серый, пройденное
за тик — оранжевое, имя меча у кончика).

**Удар и рывок.** Слой действий у всех бойцов: `AnimatorAction` (`ActionLayer`: `StartAttack`, `Begin`, `Tick`, `CanAct`, `CanAttack`,
`TurnScale`, `MoveScale`), позы — `ActionPoses`. Команда игрока `PlayerCommand` (`Attack`, `Stab`, `Gesture`, `Dash`) → буферы
(`PlayerControl`: удар 0,3 с, рывок 0,2 с, перезарядка рывка 0,6 с; рывок раньше удара). Выбор удара — `AttackPicker` (`AttackCombo`):
связка slash1–4 без повтора клипа, сброс через 1,6 с, жест — ближайший замах, укол (Q) — поток `combat.player-pick`. Снимок позы — при
прерывании видимого действия и на конце клипа с видимым весом (запрос в состоянии, копия — `core.action-snapshot`). Удар слоем верха —
`PosePool.BlendMasked` по маске `ActionRules.UpperMask` с долей клипа в ногах (`Stand`), переход от снимка — по маске всего тела; оба с
памятью смешивания (перескочившая дуга догоняется не больше 8° за тик); хвост удара на бегу обрезается. Рывок — прибавка
`DashSpeed·(1 − smoothstep(t/DashTime))` в сторону хода (без хода — назад от курса), скорость хода (`RootVelocity`) не трогает; вид —
клип уклонения всем телом (отрезок 0,45 с за время рывка), root motion клипа не применяется; неуязвимость — `PlayerControl.Invulnerable`.
Игрок управляет всегда: `MoveScale` 1 при любом действии, поворот 0,6 в окне урона, удар прерывает рывок и удар после окна урона, рывок —
любое действие. Враг — по правилам не-`Agile`: связка через 0,1 с после окна, в ударе поворот и ход 0,35. Удар ИИ
(`EnemyAiSystem.Attack`, таймер `EnemyAttack`, поток `ai.attack`): таймер ≤ 0, ближе `Reach` 2,3 м и `CanAct` — 75 % рубящий, иначе укол.
Удар врагу командой — `EnemyCommand.Attack` (поверх ИИ на тик). Жест (клиент): сдвиг мыши с затуханием 0,85^(60·с), порог 12 пикс., на
клике — удар, чья траектория на экране ближе к жесту (`StrikeGesture.Pick`); в команду — направление в системе бойца. Постройка заново:
действие и снимок — с нуля, номер удара и счёт снимков — прежние, `PlayerControl` — с нуля, связка — прежняя, таймер врага — новый.

**Проходы клинка** (`StrikeDetectionSystem`). Пары — только игрок ↔ враг; атакующий — живой в ударе; жертва — живая или труп.
Скорость кончика `|tip − prevTip|/dt` не меньше 3,5 м/с; отсечение — `|центр − кончик| > радиус + 1,5 м` по 13 капсулам плоти этого
тика; развёртка — 4 положения клинка прошлый → нынешний против капсул жертвы (радиус + 0,02, `Segments.SegSeg`), первое положение с
касанием — ближайшая капсула, точка `c2 + normalize(c1 − c2)·r`. Одно попадание за проход (номер удара), кулдаун пары 0,1 с, касание
слабее порога урона 4 проход не тратит. Урон — `((укол ? 12 : 8) + min(v, 16)·(укол ? 1,2 : 1,4))·(игрок ? combat.playerDamage : 1)`.
Состояние пары — компонент врага `StrikePairs` (с нуля при каждой постройке; ведётся и у мёртвых). Касание трупа — по его телам на
физике после шага тика; тело клинка (сегмент 11) — не цель.

**Попадание** (`HitApplySystem`, `DamageRules`). Неуязвимость (`combat.playerInvulnerable`, рывок) — касание без попадания. Живому:
`Hp −= урон·HpMul[часть]`, рана `min(1,5, рана + урон/45)`, `Bleed += урон·0,02`; смерть — очков ≤ 0 или рана торса ≥ 1,4; смертельный
укол — только остриём вперёд (доля движения кончика вдоль оси клинка > 0,6); урон выше порога отруба (`SeverThreshold`, удар игрока —
÷ острота) — заявка `SeverRequested` без ответа (решение 17). `Health` меняет только команда `Set`; `Dead` — время и причина (`Hit`,
`Probe`, `Bleed`, `Command`). По трупу (мёртв до попаданий тика): урон и рана — в его `Health`, кровопотери нет, заявка на отруб — как у
живого, второй смерти и реакции нет, `Hit.Corpse = true`; убитый прошлым касанием этого тика — не цель. **Импульс удара** (`HitImpulses.Apply`):
`min(урон·0,25, 12)` Н·с вдоль движения кончика в точке касания; трупу — `PassHit` → `ApplyHit` (потолок Δv точки 0,5 × скорость
удара, списание из прохода, отдача атакующему), убитому этим ударом — в ещё кинематическую часть (переход в труп в Settle урежет скорости
до 6 м/с); запись — компонент жертвы `HitImpulse`. Проба — без импульса.

**Реакции.** Враг — клип реакции действием `HitReact` (сзади `hit_back`, спереди `hit_front1`/`hit_front2` — поток `combat.hit-react`;
`Busy`, ход 0,15, поворот 0,35, бить нельзя; снимок при прерывании удара); начинается в React — снимок и поза слоя в Animation следующего
тика. Игрок — вздрагивание (`FlinchLayer`, компонент `Flinch`): два слота, добавка поворотов по маске верха (`PosePool.AddMasked`, вес
0,8 · огибающая; длина 0,55 с, вход 0,06, выход 0,2), прошлый слот гаснет от своего веса, пока другой виден — новое не начинается;
корень, ход и действия не трогаются.

**Кровопотеря, смерть, возрождение.** `BleedSystem` (Aftermath): `Hp −= Bleed·dt`, `Bleed = max(0, Bleed − 0,2·dt)` — `Set<Health>` только
кровоточащим. Мёртвого пропускают системы ядра (команда игрока, ИИ и команда врагу, курс и разгон, аниматор, слои позы, перенос корня,
столкновения корней, постановка капсул и клинка) и модуль Locomotion; его тела ставит физика — переход в труп в тике смерти (Gameplay —
смерть командой сцены, Settle — от удара и кровопотери; скорости ≤ 6 м/с и 20 рад/с, сустав запястья выключен — меч выпадает; «Рэгдолл»).
Корень мёртвого — за тазом трупа (`core.corpse-root`), клинок-отрезок стоит, где был в тик смерти. Живые проходят сквозь трупы в
столкновениях корней, но толкают их телами и клинком. Мёртвый игрок: команды не действуют, враги подходят ×0,2 к его корню и не бьют
(удар командой врагу — вид; клинок врага по трупу игрока — попадание по трупу); R строит игрока заново. Возрождение врага
(`RespawnSystem`): в первом тике, где `Time − DeadTime > 8` (смерть на тике N — возрождение на N + 961 при 120 Гц), `Fighters.Rebuild` —
кольцо вокруг корня игрока, новый меч и таймер ИИ (партия `ArenaRules.RespawnBatch`), здоровье и пары удара с нуля, `Dead` снят, тела —
снова кинематика; следующий тик видит нового бойца.

**Проба удара командой** (`StrikeProbe` {атакующий и жертва — места, часть, урон, вид}) — синтетическое касание в конце Combat: точка —
центр капсулы части, направление и ось — от корня атакующего к жертве; дальше — тот же путь Resolve; проходы и кулдаун пар не трогает.

**Статистика** (`ArenaStats`, Settle): убито — все смерти врагов (от удара, пробы, кровопотери, команды сцены; удар по трупу — нет);
попаданий — по живым; по трупам — `CorpseHits`; последний удар игрока (часть, урон, порог отруба) — и по трупу; R — с нуля.

**Причинность** (`CombatCauses`). Команда игрока с `Attack`/`Stab` или решение ИИ «удар по таймеру» → «начало удара» (боец, номер
удара) → `StrikeContact` → `Hit` → `Set<Health>`, `Add<Dead>`, `SeverRequested`, `HitImpulse`; реакции — от `Hit`; кровопотеря — от
последнего попадания; возрождение — от смерти; ручка — от команды `TuningCommand`. Режим причинности хеш, реплей и выделения не меняет.

**HUD, инвентарь, ручки, F3.** HUD боя — снимок мира последнего тика кадра (`CombatHud`): «ФИЗИКА И БОЙ» (враги живых / всего, убито,
попаданий), полоса «HP n» внизу, последний удар над ней, экран «ПАЛ», кольцо игрока по здоровью (`PlayerHpFrac`), подпись меча и справка.
Инвентарь — панель клиента `InventoryPanel` (I; 1–9 и щелчок — команда арены `EquipWeapon` из `ArenaClient.BeforeTick` после PageUp,
PageDown, R, T; мышь над панелью не бьёт). Ручки «Бой» — ручки симуляции (`SimulationBuilder.Tuning<CombatRules>("combat")`): изменение —
команда `TuningCommand {Knob, Value}` (ключ — хеш имени) → `tuning.combat` в Begin прижимает к диапазону и заменяет `CombatRules`
(`ResourceChanged`, в реплее); нечисло и незнакомая ручка — ничего. Панель F3 (`Engine.DevTools/TuningPanel`, группа «Бой» —
`CombatTuning` над `Engine.Client/TuningBinding`): чтение — ожидающее значение или мир, запись — команда на ближайший тик, «сброс» — к
значениям в коде, «сохранить»/«загрузить» — секция `combat` в `sword.user.json` (бережно: чужие секции, порядок, комментарии, CRLF).

**Числа по умолчанию.** Удар игрока клинком быстрее 16 м/с — 2·(8 + 16·1,4) = 60,8, укол — 2·(12 + 16·1,2) = 62,4; удар врага — 30,4 и
31,2. Очки жизни 100: голова ×1,6, торс ×1, таз ×0,9, бёдра и голени ×0,5, руки ×0,4, стопы ×0,3. Порог отруба: торс 75, голова 27,
плечо 25,2, предплечье 18, бедро 37,2, голень 26,4, стопа 18 (удар игрока — ÷ острота). Дуэль: 4 попадания игрока до смерти врага;
стоящего игрока три врага убивают за 6,5 с (6 попаданий). Пробами по 60,8: голова — 2 попадания, торс — 2, бедро — 4, плечо — 5,
стопа — 6. Удар ИИ: таймер при постройке 1 + ГСЧ·2 с, после удара 1,1 + ГСЧ·1,4 с (в среднем 1,8 с), только ближе 2,3 м. Рывок: стоя —
назад 1,46 м; на бегу — 9,60 м за 240 тиков против 8,13 м без рывка. Импульс удара по трупу — 5,9…12 Н·с (сценарий s1 «Рэгдолл»).

**Память.** Бой после прогрева — 0 Б/тик: пул поз заранее на арену из конфига (`GameCore.ReservePoses`: (`arena.enemies` + 1) × 11 поз
и × 16 заданий; прибавку врагов добирает `ArenaCommandSystem` в тике команды), буферы команд систем боя — `SystemSetup.ReserveCommands`
(`CombatReserve`); запас в логику пула и хеш не входит (`state.describe animation` — `reserved`, `jobsReserved`).

## Настройки

- `combat.playerWeapon` — меч игрока при старте (имя файла пака без расширения, без учёта регистра; по умолчанию `sword_1h`); неизвестное
  имя — ошибка конфига с перечнем мечей.
- `combat.enemiesAttack` (`true`) — враги бьют по таймеру ИИ; `false` — мирные враги (регрессия: эталоны SWORD2, сценарии
  `enemies`, `bodies`, `profiler`). Удар командой врагу действует и так.
- `combat.playerInvulnerable` (`false`) — касания клинков врагов есть, попаданий нет.
- `combat.playerDamage` (2) — множитель урона ударов игрока; `combat.playerSharpness` (1) — острота: порог отруба ÷ острота (не меньше
  0,05). Не число или меньше 0 — ошибка конфига.
- Рывок: `combat.dashSpeed` (9,5 м/с), `combat.dashTime` (0,3 с), `combat.dashCooldown` (0,6 с), `combat.dashInvulnerable` (0,3 с); не
  число, меньше 0 (время — не больше 0) — ошибка конфига.
- Ручки «Бой» (F3, команда `TuningCommand`): `combat.playerDamage` 0,2…5 (лог.), `combat.playerSharpness` 0,1…3 (лог.),
  `combat.enemiesAttack`, `combat.playerInvulnerable`, `combat.dashSpeed` 0…20, `combat.dashTime` 0,05…1, `combat.dashCooldown` 0…3,
  `combat.dashInvulnerable` 0…1; по умолчанию — значение в коде; «сохранить» — секция `combat` в `sword.user.json`.
- Ввод (секция `input`): `attack` (ЛКМ), `stab` (Q), `dash` (Пробел), `next_weapon` (T), `inventory` (I), `weapon_1`…`weapon_9` (1–9 при
  открытом инвентаре), `tuning` (F3 — панель ручек, DevTools).
- `Sword.exe --overlay blades` — клинки с первого кадра; `--minimized` — окно свёрнутым без фокуса; `--stall N` — сторож кадров
  проверочного прогона (`--frames`, `--bench`; 60 с): нет кадров N с — ошибка и код выхода 5.

## Зависимости

Ядро игры: Game.Contracts (`Combat.cs`, `Damage.cs`), Game.Data (`WeaponMesh` → Formats), Animation (клипы, пул поз: `BlendMasked`,
`AddMasked`, поза кисти), Engine.Geometry (`Segments.SegSeg`), Physics (тела жертвы, импульс — `PassHit`/`ApplyHit`), тела бойцов
(«Физика и тела»), труп, толчки и отдача («Рэгдолл»), модуль Locomotion (поза бойца; без него — поза привязки, клинок и меч всё равно на

## Что проверить в игре

Ручная проверка — 10 пунктов по темам: клавиши, что должно происходить, на что смотреть. Те же
пункты — `checklist` в [feature.json](feature.json) (тест `FeatureManifestsTests` сверяет).

1. Мечи: `Sword.exe` — у каждого бойца меч в правой руке, у врагов разные (катаны, широкие, одноручный); меч идёт с кистью без отставания и дрожи в стойке, на бегу и в ударах. F7 — поверх капсул тел отрезки клинков (враги — белые, игрок — жёлтый, клинок прошлого тика — серый, пройденное за тик — оранжевые стороны), клинок лежит вдоль меча. PageUp / PageDown / R — как раньше; R строит врагов заново с новыми мечами.
2. Оружие игрока: T — следующий меч по кругу (6 мечей пака); справа внизу «оружие: sword_1h    I — инвентарь»; I — панель справа (строка на меч с номером, зелёная точка у выбранного), 1–9 и щелчок по строке меняют меч в руке, щелчок по панели не бьёт, I — закрыть; R меч игрока не сбрасывает.
3. Удары: ЛКМ — удар, нажатия во время удара — связка из 4 разных ударов, каждый сразу после окна урона прошлого (пауза дольше 1,6 с — связка с начала); Q — укол; быстро повести мышью (влево, вправо, вниз) и сразу ЛКМ — удар идёт в ту сторону экрана, и после поворота камеры (Z/C) тоже.
4. Отзывчивость: бег (WASD) и ЛКМ — ноги бегут, руки бьют, бег не замедляется, после удара руки сразу уходят в бег; Пробел — быстрый рывок в сторону хода (стоя — назад), после него бег с той же скоростью, без провала; чаще раза в 0,6 с рывок не выходит; Пробел и сразу ЛКМ — удар из рывка без задержки.
5. Враги бьют: подошедшие вплотную замахиваются (рубящие и уколы, раз в 1–2,5 с); попадание в игрока — верх тела вздрагивает, а бег, поворот, удар и рывок слушаются без задержки; полоса «HP 100» внизу укорачивается, кольцо под игроком из зелёного — жёлтое, затем красное; Пробел в тот миг, когда клинок врага идёт в игрока, — урона нет (неуязвимость рывка 0,3 с).
6. Смерть врага: попадание — враг отшатывается (клип спереди или сзади по месту попадания), несколько мгновений не бьёт и почти не идёт; после 3–5 попаданий падает — труп на физике, меч выпадает, живые проходят сквозь труп, чуть толкая его, удары по трупу ранят и толкают его, но «убито» не растёт; над полосой — последний удар игрока («голова 61»); через 8 с убитый появляется на кольце вокруг игрока с новым мечом и снова идёт в бой.
7. HUD боя: слева вверху «ФИЗИКА И БОЙ» — враги (живых / всего), убито (и от кровопотери), попаданий; PageUp / PageDown меняют «всего»; R — «убито», «попаданий» и строка последнего удара — с нуля.
8. Смерть игрока: стоять и не отвечать — враги убивают за несколько секунд: экран темнеет, крупно «ПАЛ», ниже «убито N · R — снова в бой»; WASD и ЛКМ не действуют, враги подходят медленно и не бьют; R — игрок живой, полоса полная. `Sword.exe --set combat.playerInvulnerable=true` — урона нет вовсе.
9. F3 — панель ручек слева под HUD, вкладка «Бой»: «урон» 5 — враги умирают с 1–2 ударов, 0,2 — почти не ранятся (строки «последний удар» и «максимум удара» меняются); «враги нападают» выкл — не замахиваются; «игрок неуязвим» — клинки проходят, HP не убывает; ползунки рывка меняют рывок; ПКМ по подписи — к значению по умолчанию, «сброс» — все; щелчок и протяжка по панели не бьют.
10. «сохранить» в F3 — «сохранено значений: N (sword.user.json)»; перезапустить игру — ручки те же; изменить и «загрузить» — вернулись сохранённые, прочее в sword.user.json на месте. Справка F1 называет ЛКМ, Q, Пробел, T, I, 1–9 и F3. Толпа: `Sword.exe --replay artifacts/features/combat/scenario-crowd.swreplay --overlay blades` (после verify.ps1) — 32 врага рубят неуязвимого игрока, он рубит в ответ, убитые падают (труп на физике) и через 8 с возрождаются; кадр плавный.

## Решения и почему

Подробно — [история](../../../../docs/history/combat.md) («Отличия от SWORD»).
- Команды арены — в Begin: Intent того же тика видит арену после команд.
- Таблица оружия — в симуляции рядом с `CharacterAssets`, чтение `.swmesh` — Game.Data (формат игре не виден); неизвестное имя меча —
  ошибка конфига, меш со суставами или без клинка — ошибка загрузки.
- Смена меча не даёт прохода между клинками (клинок другим мечом — без прошлого); меч врага — своя выборка ГСЧ: расстановка не
  сдвинулась.
- Удар и вид рывка — в слое действий аниматора; снимок — запрос в состоянии, копия — первой в Animation.
- Рывок — прибавка скорости контроллера, а не root motion (`Evade` SWORD): после рывка ход тот же, без провала и инерции (решение
  пользователя).
- Игрок управляет всегда — цель «максимально отзывчивый бой»: `MoveScale` 1, рывок прерывает любое действие.
- Жест — в системе бойца с учётом камеры и курса (в SWORD жест «вправо» у бойца лицом к камере давал удар влево).
- Смешивание по маске и переход от снимка — с памятью: кратчайшая дуга перескакивала (таз до 180° за тик, плечо до 116 м/с).
- Буферы и перезарядка — в симуляции, не ниже 0; R обнуляет их и рывок.
- Протокол боя — событиями; стадия Defense пуста (решение 16), отруба нет (решение 17).
- `Health` — реактивный компонент (только `Set`): причина каждого изменения.
- Касание слабее порога урона проход не тратит; смертельный укол — только остриём вперёд; отсечение — по 13 капсулам этого тика.
- «Убито» — любые смерти врагов; последний удар сбрасывается по R; пары удара — с нуля при каждой постройке.
- Реакция врага — в React, после Animation; клип реакции и место возрождения — счётчиковый ГСЧ, кольцо вокруг корня игрока.
- Вздрагивание без скачков: прошлый слот гаснет от своего веса, третье попадание при видимых слотах — без нового.
- Удар врагу командой, проба удара командой, мирные враги — новое, для агента и сценариев.
- Ручка — ручка симуляции Runtime (команда в реплее, ключ — хеш имени); клиент игры не видит Runtime — `TuningBinding`.
- HUD — снимок мира в Extract; инвентарь — панель клиента в слое панелей движка.
- Запас памяти пула поз и буферов команд на арену из конфига — 0 Б/тик в бою, хеши те же; перед замером «0 Б/тик» JIT греется до
  затишья (≤ 1 с) — проверка не ослаблена; проверочный Sword.exe рисует и свёрнутым, со сторожем кадров — не висит.
- Сравнения со SWORD сняты — свой путь (решение 14); эталон боя не снимается (решение пользователя 2026-09-24).
- Трупы — цели: попадания по трупу — отдельный счёт (`CorpseHits`), дуэль и пробы по частям — прежние числа; проба в труп —
  без импульса (скорости удара нет); убитый прошлым касанием тика — не цель (тело ещё кинематическое).
