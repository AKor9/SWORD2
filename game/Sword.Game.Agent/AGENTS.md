# Sword.Game.Agent — правила

Агентский доступ игры: то, что знает только игра. Сейчас — имена сущностей (`SwordAgent.ArenaNames`: `player`,
`fighter N`). Ядро игры и модули об агенте не знают; игровые виды, сценарии и пробы боя — со своими этапами.

- Имя — подсказка, не идентичность: в ответах сущность всегда и номером.
- Исполняется в точке обслуживания: только чтение мира.

Проверка: `verify.ps1` шаг `agent-smoke` (`entity.get player`).
