# Sword.Game.Data — правила

Игровые данные и форматы (раздел 9 плана): то, что читают и игра, и модули, и (позже) пекарня. Сейчас — таблица
действий бойца: слоты (`ActionSlots`: ключи `combat/actions.json`, подписи, клипы по умолчанию, слои) и их клипы для
библиотеки (`ActionTable.Resolve`). Логика — `CharacterRig` SWORD 2eab13b (слоты, `LoadActions`); запись выбора
(`SaveActions`) — с редактором анимаций (этап 14).

- Без логики игры и без движка анимации: клип ищет переданная функция, таблица — только имена и номера.
- Порядок слотов — порядок SWORD; номера слотов локомоции — `ActionSlots.Idle`, `Walk(dir)`, `Run(dir)`.
- Ошибки выбора (неизвестный слот, нет клипа, неверный слой) — предупреждения, прежнее значение остаётся, как в
  SWORD; испорченный JSON — `InvalidDataException`.

Дальше сюда — риг (данные `CharacterRig`), оружие, кровь оружия, анатомия (по этапам своих фич).
