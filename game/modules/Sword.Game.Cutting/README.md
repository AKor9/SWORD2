# Модуль Cutting — расчленение (симуляция)

Модуль `cutting` (решение 21) решает, что делает удар с частью тела, и шлёт событие отделения. Применяет его ядро. Меш режет
клиентская часть — [Sword.Game.Cutting.Client](../Sword.Game.Cutting.Client/README.md). План — `artifacts/plans/dismemberment/PLAN.md`
(вне git).

## Как решает

На каждое засчитанное попадание ядро шлёт заявку `SeverRequested`: точку, ось клинка, скорость точки клинка, вид удара, остроту.
Модуль решает в стадии Dismember (`SeverDecisionSystem`).

- **Клинок** (`SeverPhysics`). Энергия удара — `½ · effectiveMass · v⊥² · острота`, где v⊥ — скорость точки клинка поперёк его оси.
  - Плоскость проходит через ось клинка и направление его хода. К оси части она не ближе 30°.
  - Сечение в месте разреза — эллипс по профилю ткани (`TissueProfiles` ядра). Мягкие ткани и кость считаются со своей удельной энергией.
  - Хватило энергии — отруб (`LimbDetached`, `Cut`). Культя тянется от сустава до разреза, массы делятся по объёму профиля, импульс
    куску — работа разреза / скорость.
  - Не хватило — неполный разрез (`PartialCut`) с глубиной.
  - Кусок меньше `minPiece` объёма не отделяется. Таз не режется.
  - Укол (Q) режет так же — поперечной долей хода клинка; прямой укол вдоль клинка — прокол (неполный разрез).
- **Тупое** (`ImpactPhysics.Blunt`, оружие из `combat.bluntWeapons`, по умолчанию `maul`). Энергия — `½ · bluntMass · v²`, импульс — удар
  двух тел.
  - Голова выше `headCrush` — в клочья (`Shatter`).
  - Энергии хватает на сечение у сустава — отрыв (`Tear`).
  - Хватает на сечение кости — перелом (`Fracture`): культя и кусок на слабом суставе.
- **Взрыв** (`ImpactPhysics.Blast`, заявки ядра от команды `BlastCommand`).
  - Энергия части выше 80 Дж/кг — клочья.
  - Иначе — отрыв, если энергия разности скоростей части и родителя больше прочности сустава.
  - Толкает тела ядро.

Номер куска (`LimbDetached.Piece`) модуль считает по кускам бойца и заведённым в тике. У разреза и перелома он же решает, какие дети
сегмента уходят с куском (`LimbDetached.Carried`): те, чей сустав с сегментом по сторону куска от плоскости. Косой срез у плеч уносит
голову и верхнее плечо, нижнее остаётся на культе; меш режется по той же маске. Ядро проверяет событие и применяет его в React
(`SeverAftermathSystem`). Там новые тела сочленения со скоростями материи, суставы ушедших детей — на кусок (`Severance.Holder`),
оставшихся — на культю, ветвь живого — на физику, привязки скина. Импульс удара отделённому не разгоняет его выше потолков профиля
трупа. Без ноги, головы или торса живой мёртв.

## Настройки (секция `cutting`, ручки F3 «Расчленение»)

| ключ | по умолчанию | что |
|---|---|---|
| `effectiveMass` | 3 кг | масса клинка с рукой в точке касания |
| `softToughness` | 2000 Дж/м² | разрез мягких тканей на площадь |
| `boneToughness` | 60000 Дж/м² | разрез кости на площадь |
| `minPiece` | 0,03 | наименьший кусок, доля объёма части |
| `bluntMass` | 6 кг | масса тупого оружия с руками |
| `boneFracture` | 300000 Дж/м² | перелом на площадь сечения кости |
| `tearToughness` | 60000 Дж/м² | отрыв на площадь сечения у сустава |
| `headCrush` | 350 Дж | голова в клочья |

`modules.cutting.enabled` (по умолчанию `true`); сборка без модуля — `-p:WithoutCutting=true` (убирает и клиентскую часть). Острота игрока
(`combat.playerSharpness`) умножает энергию разреза его ударов.

## Ограничения

- Кусков у бойца не больше 16 (`Severance.MaxPieces`). Куски живут, пока живёт тело бойца: при возрождении и сбросе арены их убирает
  постройка.
- Куски нельзя рубить снова (цели ударов — только 13 капсул бойца). Отделённое у живого — не цель.
- Таз не режется: дети крепятся к нему с разных концов.
- Числа прочности — порядок величин, их подгоняют ручками.

## Что проверить в игре

- Сильный удар мечом по руке, ноге, шее: часть отлетает с красной крышкой среза, на культе — тоже срез. Слабый удар не рубит.
- Торс пополам: верх летит с головой и руками одним куском, без щелей у плеч. Косой срез у плеча — рука, чьё плечо ниже среза,
  остаётся с нижней частью.
- Без руки враг продолжает бой, без руки с мечом — меч падает. Без левой руки меч остаётся в правой кисти. Без ноги или головы —
  падает трупом.
- Молот (`T` или инвентарь `I` → maul): по предплечью — перелом, рука гнётся в месте удара. Сильнее — рука отрывается с рваным краем.
  По голове — голова разлетается на куски.
- `B` — взрыв у курсора (энергия и радиус — F3 «Расчленение»): тела разлетаются, вблизи рвутся части.
