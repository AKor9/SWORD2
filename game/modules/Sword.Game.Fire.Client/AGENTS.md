# Sword.Game.Fire.Client — правила

Модуль `fire` (клиентский): огонь на горящем оружии игрока — пламя (сим Fluid2D на шишке), дым (3D-газ Fluid3D в мире, окно за шишкой),
свет. Устройство, числа, отступления от L2 — [README.md](README.md).

Инварианты:
- Только представление: мир ECS не читается (оружие — сервис `IWeaponTips`), в симуляцию, хеш и реплей модуль ничего не пишет.
- Шаг сима пламени и газа — по `TickId` (60 Гц, заявки `FireStep`/`FireGasStep`), время пламени и LF — по тикам и доле тика: реплей с тем
  же темпом кадров даёт те же поля (`fieldHash`, `fire.gas.sims[].fieldHash`) и тот же HDR; часов кадра нет.
- Дым стоит в мире: окно газа сдвигается только целыми ячейками (Fluid3D), цель окна — CPU (`FireGasSlots.WindowTarget`); поворота сетки нет.
- Дым из пламени: карту шага (`fire.gas.feed`) пишет сим пламени раньше газа того же шага — симы `fire.N` регистрируются до `fire.gas.N`;
  ветер — один на оба сима (`FireTuning.Wind` → `Fluid3DParams.Wind`).
- Формула меняется в двух местах сразу: шейдер `Shaders/fire/*.hlsl` и CPU-эталон (`FlameMath`, `SmokeMath`, `FireLightMath`); раскладка
  констант — `_Static_assert` с C#.
- Кадр — 0 Б: ресурсы — при старте на `maxFires` экземпляров (газ ≈42 МБ каждый), делегаты проходов — поля.
- Нет горящего оружия в паке — ни сима, ни газа, ни проходов; модуль выключен — ни одного прохода и ресурса.
- Порядок в Transparent: дым (слой ½, марш по газу) раньше пламени. Пропуск пустоты не меняет результат: сетка занятости с запасом ячейки
  (кирпич 4³ читает ячейки 4b − 1…4b + 5) — сужать запас нельзя; контроль — `SkipEmpty_SameResultAsFullMarch_SameSamples`.

Проверка: `dotnet test tests/Sword.Game.Tests --filter "FullyQualifiedName~Fire|FullyQualifiedName~Torch"` (GPU-тесты — пак игры);
`verify.ps1 -Only without-modules`.

Видно: `Sword.exe --json` → `fire` (`sims`, `gas`, `metrics`, `flame`, `smoke`, `light`, `checks`), оверлеи `fire`, `fire.field`,
`fire.flame`, `fire.smoke` (вклад дыма), `fire.gas` (окно газа), `lights`, снимок `<снимок>.fire.*` и срезы газа
`<снимок>.fire.gas.xy|xz.*`, ручки `--tune fire.*` (окно газа — `fire.gasView=1`); столб
дыма по высоте — `fire.gas.sims[].profile`, `column`.

Типичные ошибки: правка шейдера без эталона; чтение поля GPU посреди кадра (только при выходе или асинхронно); сравнение цвета пламени
с кадрами L2 без ночи (`--tune light.night=1`); `--camera` ближе 3 м не подходит (крупный план — 3 м); метрика «дым стоит в мире» (`drift.ratio`) — только при
движении шишки (`knobPathM` > 5 см), иначе 0.
