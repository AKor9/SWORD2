# Sword.Game.Impact — правила

Модуль `impact` (решение 22), часть симуляции: сила удара. Описание — [README.md](README.md); план — `artifacts/plans/impact/PLAN.md`
(вне git).

- Модуль не видит ядро игры и другие модули: вход — заявки `SeverRequested` (та же, что у Cutting) и `IPhysicsWorld` (только
  чтение, центр масс — таз), выход — событие `HitResponse` и свой компонент `Balance`. Действие, вздрагивание, толчок, падение и
  вставание исполняет ядро.
- Физика решений — чистые функции (`ImpactPhysics`), их проверяют тесты без мира (`ImpactTests`).
- Игроку — только вздрагивание (уровень `Flinch`): управление не отнимается (цель боя пользователя).
- Попадания одного тика по жертве копятся по порядку заявок; память — массивы полей, тик без выделений.
- Без модуля игра стартует (решение 9): нет откликов — нет реакций.

Проверка: `dotnet build SWORD.slnx`; `dotnet test tests/Sword.Game.Tests --filter "FullyQualifiedName~ImpactTests"` (на паке — сцена
`artifacts/impact/scene.swreplay` для `Sword.exe --replay`); при изменении поведения — `verify.ps1 -Only headless-smoke,replay-smoke`.

Типичные ошибки: импульс от урона, а не от скорости точки оружия; толчок игрока через `RootVelocity` (его гасит управление —
толкает `Shove`); два `Add<Downed>` в одном тике (падение от перелома ноги ставит ядро отделения, отклик его пропускает).
