# Модуль Impact — сила удара (симуляция)

Модуль `impact` (решение 22) превращает каждое попадание по живому в физический импульс и решает отклик тела. Исполняет отклик ядро
(`HitReactionSystem`, сбитый с ног — `KnockdownSystem`, вставание — `RiseSystem`). План — `artifacts/plans/impact/PLAN.md` (вне git).

## Как решает

На каждое попадание по плоти ядро шлёт заявку `SeverRequested` (точка, скорость точки оружия, вид удара, атакующий). Модуль решает в
стадии Dismember (`ImpactSystem`), рядом с модулем Cutting — оба читают одну заявку.

- **Импульс.** Тело — одно твёрдое тело (масса `bodyMass`, инерция `bodyInertia` вокруг центра масс — таза). Оружие встречает в точке
  приведённую массу `μ = m_w·m / (m_w + m)`, `1/m = 1/M + |r × n|²/I`: удар в грудь передаёт больше, чем по кисти (часть уходит во
  вращение). `J = μ · v · (1 + e) · k`: `k` — доля клинка `bladeShare` (рез гасит удар), у молота — 1.
- **Баланс.** Скорость центра масс `Δv = J / M`; точка захвата (куда надо шагнуть, чтобы устоять) уходит на `Δv / ω0`,
  `ω0 = √(g / comHeight)`; удар по ногам — × `legFactor`. Сдвиги копятся и гаснут за `recovery` (компонент `Balance`).
- **Отклик** (`HitResponse`): меньше `staggerShift` — вздрагивание с силой по доле порога; меньше `fallShift` — пошатывание; больше —
  падение. Игрок только вздрагивает и отъезжает — управление не отнимается. Толчок корня — `Δv` по земле (не больше `maxPush`).
- **Отдача оружия** — доля импульса оружия, которую забрало тело: клип удара атакующего замедляется до `1 − доля` и за 0,15 с плавно
  набирает прежнюю скорость (молот в грудь вязнет, клинок, разрубив, идёт дальше).

Ядро исполняет: враг на каждое попадание играет реакцию (прерывает удар), пошатывание с толчком от 0,8 м/с — сильным клипом
`hit_big`; вздрагивание добавкой с силой удара — у всех; толчок — затухающий сдвиг корня (`Shove`, 0,25 с). Падение: тела — на физику
(меч в руке), полежав спокойно, боец встаёт клипом `stand_up` от позы тел; сломанная молотом нога валит без вставания.

## Настройки (секция `impact`, ручки F3 «Сила удара»)

| ключ | по умолчанию | что |
|---|---|---|
| `bladeMass` | 3 кг | масса клинка с рукой |
| `bluntMass` | 6 кг | масса молота с руками |
| `bladeShare` | 0,35 | доля импульса клинка, дошедшая до тела |
| `restitution` | 0,2 | упругость удара |
| `bodyMass`, `bodyInertia` | 75 кг, 10 кг·м² | тело |
| `comHeight` | 1 м | высота центра масс |
| `staggerShift` | 0,12 м | сдвиг точки захвата: пошатывание |
| `fallShift` | 0,45 м | сдвиг точки захвата: падение |
| `legFactor` | 1,6 | удар по ногам |
| `recovery` | 0,5 с | восстановление баланса |
| `minFlinch` | 0,15 | наименьшая сила вздрагивания |
| `maxPush` | 2,5 м/с | наибольший толчок корня |

`modules.impact.enabled` (по умолчанию `true`); сборка без модуля — `-p:WithoutImpact=true`: попадания не толкают, реакций и падений нет.

## Ограничения

- Отдача — замедление клипа удара, не отскок клипом.
- Первый удар каждого вида не компилирует JIT в тике игры: при запуске игры бой прогревается в фоне отдельной симуляцией
  (`CombatWarmup`, около 1,2 с; в логе — «прогрев боя»).
- Клип вставания один: лёжа ничком боец встаёт им же — переход от позы тел за 0,45 с.
- Сбитый со сломанной ногой не встаёт и лежит, пока жив.

## Что проверить в игре

- Меч по врагу: вздрагивает сильнее от быстрых ударов, игрок от ударов врагов вздрагивает и чуть отъезжает.
- Молот в грудь: враг отшатывается сильным клипом и отъезжает; молот вязнет в теле. Два-три удара молотом подряд (или по ногам) —
  враг падает телом на физике, полежав, встаёт.
- Молот по голени или бедру — кость ломается (кожа гнётся, не режется), враг падает и не встаёт.
