# Sword.Game.Cutting.Client — правила

Клиентская часть модуля `cutting` (решение 21): разрез меша кожи и крышки. Описание — [README.md](README.md).

- Только представление: мира ECS не видит, игра приходит сервисами `Game.Contracts`; в симуляцию, хеш и реплей не пишет.
- Меш строится только из записи (`LimbDetached`: плоскость в системе тела сегмента) и позы тика отделения (`IFighterPoses` в наблюдателе
  тиков) — перемотка реплея пересобирает тот же меш.
- Разрез — в фоне, разрезы бойца — по очереди; кадр не ждёт: до готовности боец рисуется прежними частями.
- Вершины основы в производном меше — на прежних номерах (`SkinCuts.Expand`): слой крови по вершинам читается по номеру вершины.
- Резак (`MeshCutter`, `CapTriangulator`) — методы пути разреза помечены `AggressiveOptimization`: код редкий, первые разрезы без
  него вдвое медленнее (как `MotionDatabase.Build`).
- Кадр — 0 Б: буферы заводятся при старте или растут удвоением.
- Метод кадра с долгим циклом — тело цикла в отдельный метод (OSR).

Проверка: `dotnet build SWORD.slnx`, `dotnet test tests/Sword.Architecture.Tests`, `verify.ps1 -Only without-modules`.
